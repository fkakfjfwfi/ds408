第 4 章 · 图

线性表是一对一，树是一对多，图是多对多——最自由的结构，也是 408 大题最爱出算法题的地方（遍历、最短路、拓扑）。学这章的秘诀：把第 2 章的队列和第 3 章的递归直接搬过来用。

预计学习 4~6 小时 · 动画课堂 1 集 · 图遍历实验室 1 个 · 练习 4 题 · 打卡 6 项

🎯 学习目标（学完你应该能）
① 给定图，手工写出邻接矩阵和邻接表，并分别给出唯一的/不唯一的 BFS、DFS 序列；
② 手工模拟 Prim 和 Kruskal 构造最小生成树的每一步；
③ 用 Dijkstra 的表格法算单源最短路径，知道它为什么怕负权边；
④ 对 AOV 网手工求拓扑序列，并能判断图中有无环。

4.1 先说人话：什么是图

🚇 生活类比
图就是地铁线路图：站点是顶点，轨道是边。任何两个站之间都可能直接相连，没有"根"也没有"唯一前驱"——多对多，仅此而已。微信好友是无向图（互为好友），微博关注是有向图（单方面）。

图 G = (V, E)：顶点集 + 边集。无向图的边 (v,w) 与 (w,v) 是同一条；有向图的弧 <v,w> 有方向。顶点的度 = 挂在上面的边数（有向图分入度/出度）。

📌 408 必背数字
n 个顶点的无向完全图有 n(n−1)/2 条边；有向完全图有 n(n−1) 条弧。边数达到完全图量级叫稠密图（常用邻接矩阵存），反之为稀疏图（常用邻接表存）。连通图的生成树含 n−1 条边。

4.2 存储：邻接矩阵 vs 邻接表

维度邻接矩阵（二维数组）邻接表（数组+边表）
空间O(n²)，与边数无关O(n+e)，省稀疏图
查"两点是否相邻"O(1) 直接查表O(度)
找所有邻接点扫一行 O(n)顺着边表走 O(度)
遍历序列唯一（按编号从小到大）不唯一（看边表顺序）
适合稠密图稀疏图
✅ 一句话记忆
邻接矩阵用空间换"查询快 + 序列唯一"；邻接表用"序列不唯一"换空间。选择题考"遍历序列是否唯一"，答案钥匙就是存储方式。

4.3 遍历：BFS 与 DFS（旧知识大回收）

BFS（广度优先）：像往水里扔石子，波纹一圈圈扩散——访问起点，然后把它的邻接点全部入队，一层一层向外。辅助结构：队列（第 2 章）。DFS（深度优先）：像走迷宫，一条道走到黑，撞墙再回头——辅助结构：栈/递归（第 2、3 章）。

维度BFSDFS
辅助结构队列栈（或递归）
空间复杂度O(n)（最坏队列全装）O(n)（递归深度）
时间复杂度邻接矩阵 O(n²)；邻接表 O(n+e)同左
能求什么无权图单源最短路径连通性、拓扑排序（逆序）、求关键路径配合
📌 高频结论
对连通图，从同一起点出发：邻接矩阵下的 BFS/DFS 序列唯一；邻接表下不唯一。非连通图遍历一次只能访问一个连通分量——遍历次数 = 连通分量个数（这也是判连通的方法）。
🔬 实验室：同一个图，两种走法
点 BFS 或 DFS，动画从 A 出发逐个点亮结点，右侧同步显示队列/栈的变化。先自己推一遍再对答案。
邻接表：A→B,C　B→A,D　C→A,E　D→B,F　E→C,F　F→D,E（邻接点按字母序）

4.4 最小生成树：Prim 与 Kruskal

带权连通图里选 n−1 条边把所有点连起来且总权最小。Prim（加点法）：像滚雪球——从任意点开始，每次把"离雪球最近的点"吸进来，O(n²)，适合稠密图。Kruskal（加边法）：像收购边——所有边按权排序，从小到大拿，只要不成环就要，O(eloge)，适合稀疏图。

⚠️ 两个易错点
① 最小生成树不唯一，但 MST 的总权值唯一；② Prim 从哪个点开始结果可能不同但权值和相同，手工模拟时注意"最近的点"必须从已选集合内外之间的边里挑。

4.5 最短路径：Dijkstra 与 Floyd

Dijkstra（单源）：贪心——每次从"未确定的点"里挑 dist 最小的收编，再用它松弛邻居。时间 O(n²)。经典陷阱：不能处理负权边（贪心的"已确定"前提被破坏）。Floyd（多源）：三重循环动态规划，O(n³)，代码只有四行，允许负权边但不允许负权回路。

// Floyd 核心四行（背下来，大题直接用）
for (k = 0; k < n; k++)
  for (i = 0; i < n; i++)
    for (j = 0; j < n; j++)
      if (A[i][k] + A[k][j] < A[i][j]) A[i][j] = A[i][k] + A[k][j];

4.6 拓扑排序：排课的学问

📅 生活类比
选课有先修要求：高数先于线性代数，数据结构先于操作系统。把"谁先谁后"排成一条不违反任何先修关系的顺序，就是拓扑排序（AOV 网上做）。
选一个入度为 0 的顶点输出；
删掉它和它发出的所有边（邻接点入度 −1）；
重复 ①②，直到全部输出（成功）或剩下入度全不为 0 的点（有环！）。
📌 考点三连
① 拓扑序列不唯一（同时有多个入度 0 的点时）；② 用 DFS 求的逆后序也是拓扑序；③ 拓扑排序失败 ⟺ 图有环——AOE 网求关键路径前必须先保证无环。

⚠️ 本章避坑清单

"遍历序列唯一吗"先看存储：邻接矩阵唯一，邻接表不唯一——题面给邻接表时注意边表顺序。
BFS 配队列、DFS 配栈，别背反。BFS 能求无权最短路，DFS 不能。
Prim 是"挑点"（O(n²) 稠密图），Kruskal 是"挑边"（O(eloge) 稀疏图）——选择题主战场。
Dijkstra 遇负权直接错误，真题给负权边考你"哪些顶点距离算错"。
拓扑排序输出到一半卡住 = 有环。判断有向图有无环的三种方法：拓扑排序、DFS 找回边、Kosaraju（超纲了解）。

📝 章内练习

练习 1 · 考点：完全图边数
具有 6 个顶点的无向完全图，边数是：
A. 30
B. 12
C. 15
D. 36
解析：选 C。n(n−1)/2 = 6×5/2 = 15。A 的 30 是有向完全图的弧数 n(n−1)=30；D 的 36 忘了减 1（自己不跟自己连边）。
练习 2 · 考点：遍历与辅助结构
对图进行广度优先遍历和深度优先遍历，分别借助的辅助结构是：
A. 栈、队列
B. 队列、栈
C. 都是队列
D. 都是栈
解析：选 B。BFS 一层层扫 → 先到的点先扩展 → 队列；DFS 一条路走到黑 → 最后到达的点先回头 → 栈。记忆：B=宽度=排队横着走，D=深度=竖着钻。
练习 3 · 考点：Dijkstra 适用性
关于 Dijkstra 算法，下列说法正确的是：
A. 可求解任意带权图的单源最短路径
B. 可求解图中任意两顶点间的最短路径，时间 O(n³)
C. 边权为负时只需把比较方向反过来即可正确工作
D. 基于贪心策略，边权存在负值时结果可能出错
解析：选 D。Dijkstra 把"dist 最小的点"标记为已确定，靠的是"绕路只会更远"这一前提，负权边打破它。B 描述的是 Floyd；A 缺了"无负权边"的限制条件——这正是选择题最爱挖的坑。
练习 4 · 考点：拓扑排序
对 AOV 网进行拓扑排序时，每一步应选取的顶点是：
A. 入度为 0 的顶点（多个时任选其一，故序列可能不唯一）
B. 出度为 0 的顶点
C. 编号最小的顶点
D. 权值最小的顶点
解析：选 A。入度为 0 = 没有任何先修课程未修，当前就可以"毕业"。删点减邻接点入度后产生新的入度 0 顶点；若中途找不到入度 0 的点，说明剩下的点互相等待成环——拓扑排序失败 ⟺ 有向图有环。注意 AOV 网顶点无权值，D 是张冠李戴。
