查找是数据结构"学以致用"的一章：折半查找是分治思想的第一次落地，BST 是树结构的第一个应用，散列表则是"以空间换时间"的极致。408 选择题年年考 ASL 计算，大题爱考散列表和 BST。

5.1 先说人话：查找与 ASL

📖 生活类比
查字典就是查找：从第一页往后翻是顺序查找；直接翻到中间比大小是折半查找；按拼音索引直达音节是散列。翻的次数越少，方法越好——"平均翻几次"就是 ASL（平均查找长度）。

ASL = Σ Pᵢ × Cᵢ（Pᵢ 是查到第 i 个元素的概率，通常等概率 1/n；Cᵢ 是找到它需要的比较次数）。整个第五章所有算法的优劣，都用 ASL 说话——408 的散列表大题就是让你算它。

5.2 折半查找：每次扔掉一半

int low = 0, high = n - 1;
while (low <= high) {
    int mid = (low + high) / 2;      // 取中间
    if (a[mid] == key) return mid;
    else if (a[mid] > key) high = mid - 1;  // 扔掉右半
    else low = mid + 1;                     // 扔掉左半
}
return -1;  // low > high 说明没找到

折半查找的过程画成树就是判定树：根是 mid，左子树是左半区，右子树是右半区。n 个元素的判定树是平衡的，树高 ⌈log₂(n+1)⌉——这正是最多比较次数。成功查找 ASL ≈ log₂(n+1) − 1，时间 O(log n)。

⚠️ 折半查找的前提
① 有序；② 顺序存储（链表不能折半——无法 O(1) 取中间元素）。两个前提缺一个，选择题直接判"不可用"。另外它只适合"建一次查多次"的静态表，频繁插删的动态表用 BST。

5.3 二叉排序树 BST：左小右大

🌳 生活类比
BST 像植物大战僵尸的排兵布阵：站在每个结点上，比它小的都排在左边，比它大的都排在右边。找数字时从根出发：大了往左拐、小了往右拐，一次比较砍掉一个子树——"树形版的折半查找"。
定义：左子树所有结点 < 根 < 右子树所有结点（递归成立）。
中序铁律：BST 的中序遍历序列必然递增——这是判断一棵二叉树是不是 BST 的最快方法，也是选择题高频考点。
插入：按查找路径走到底，空位就是新结点的家（新结点永远是叶子）。
删除：叶子直接删；只有一棵子树则子树顶上；有两棵子树则用中序前驱（左子树最右）或中序后继（右子树最左）顶替后再删那个顶替者。
🔬 实验室：二叉排序树
输入数字点"插入"，看它沿着查找路径落位（新结点永远是叶子）；点"查找"看比较过程。试试插入 5、3、8、2、4、7、9，再插入 1——树歪了会怎样？这正是 AVL 要解决的问题。

5.4 平衡二叉树 AVL：不许歪脖子

BST 有个致命弱点：按 1,2,3,4,5 顺序插入会退化成一条链，查找掉回 O(n)。AVL 给每个结点规定平衡因子 = 左子树高 − 右子树高，绝对值 ≤ 1，插入导致失衡时立刻旋转纠正。

失衡类型插入位置调整记忆
LL左孩子的左子树右旋左左→往右转
RR右孩子的右子树左旋右右→往左转
LR左孩子的右子树先左旋后右旋两次对折
RL右孩子的左子树先右旋后左旋两次对折
✅ 旋转的万能心法
别背四种口诀，记住一句话："把中间值转上去"。三个结点排中序，中序序列的中间那个一定是旋转后的新根——画三个圈排一排，秒出答案。n 层 AVL 最少结点数递推：N(h)=N(h−1)+N(h−2)+1。

5.5 B 树与 B+ 树（概念级）

B 树是多路平衡查找树：一个结点存多个关键字、分出多棵子树，专为磁盘块存取设计（一层 I/O 少读几块）。m 阶 B 树：每个结点最多 m 棵子树；根至少 2 棵；非根非叶至少 ⌈m/2⌉ 棵；所有叶子（失败结点）在同一层。B+ 树把数据全放在叶子层且叶子串成链表——数据库索引的标配。408 只考概念和结点数范围计算。

5.6 散列表：O(1) 的艺术

📱 生活类比
散列表就是手机通讯录：不从头翻，直接按姓名首字母跳到那一栏。散列函数 H(key) 把关键字直接映射成存储地址，理想情况一次到位 O(1)。但"张"姓太多挤在一格——这就是冲突。

冲突处理两大流派：开放定址法（被占了就按规则找下一家：线性探测 +1、+1、+1…，平方探测 +1²、−1²、+2²…）和拉链法（同义词挂成链表）。装填因子 α = 表中元素数 / 表长，α 越大越挤、冲突越多——ASL 与 α 直接挂钩，与表长无关（经典结论）。

📌 408 大题标配：散列表 ASL 计算
成功 ASL：每个元素实际插入时的比较次数之和 ÷ 元素个数；失败 ASL：从每个可能的散列位置开始走到空位的比较次数之和 ÷ 散列函数模数 p（不是表长！）。线性探测的失败查找要一直探到第一个空位——容易数错，画表逐格数最稳。
🔬 实验室：散列表（H(key) = key % 7，线性探测）
点"插入"看冲突如何发生：23→2 格，14→0 格，9→2 格被占 → 顺移 3 格。逐步插入 23、14、9，再看 30、16 怎么引发连锁堆积。
空表（表长 7，下标 0~6）。装填因子 α = 0/7 = 0。

🚀 进阶深挖（教材级）

对齐严蔚敏教材与王道复习指导的深度，含 2012~2025 真题官方解法。

深挖 1 · 折半查找判定树即 BST（2015 真题解法）

折半查找的判定树本身就是一棵二叉排序树：左子树所有值 < 根 < 右子树所有值。所以"给一个比较序列问是否可能"的万能解法：把序列按判定树走一遍，一旦向左拐，之后所有比较值必须全部小于当前拐点——出现违反即不可能。2015 年真题就是这一句话的应用。

深挖 2 · B 树删除三分支（2012、2022 连续考）

B 树删除关键字的决策链：① 在终端结点且个数 > ⌈m/2⌉−1 → 直接删；② 兄弟够借（删除后兄弟仍 ≥ ⌈m/2⌉−1）→ 旋转：父结点关键字下移、兄弟关键字上移（3 阶 B 树删 78 的 2012 真题就是"兄弟最大键上移、双亲键下移"）；③ 兄弟不够借 → 合并：被删结点 + 兄弟 + 父结点的一个关键字合成一个结点，父结点少了关键字可能继续下溢，连锁反应最坏直到根（根只剩一个关键字时树高减一）。2022 年考 5 阶 B 树删 260，同样是这条链。

深挖 3 · 分块查找：折半与顺序的折中（2025 考点）

分块查找（索引顺序查找）：块间有序（前一块最大值 < 后一块最小值），块内无序。查 ASL = 索引查找次数 + 块内查找次数。n 个元素每块 b 个，顺序查索引时 ASL = (n/b + b)/2 + …，用均值不等式取 b = √n 时最优，ASL ≈ √n + 1。2025 年真题：400 个元素每块 20 个（√400=20）正是最优分块。

深挖 4 · 散列失败 ASL 的分母是模数 p（大题杀手）

失败查找的平均长度 = 对 H(key) 的每个可能散列地址（共 p 个，p 是散列函数的模数，不是表长）从该位置走到第一个空位的比较次数之和 ÷ p。2022 年真题结论背下来：ASL 与散列函数、冲突处理策略、装填因子 α 都有关，与表长/记录数无直接关系。

⚠️ 本章避坑清单

折半查找判定树：mid 唯一确定（⌊(low+high)/2⌋），树形唯一，别自己发明取整规则。
BST 中序序列必须递增——做题先中序走一遍验证，能秒杀很多"这棵树是不是 BST"的选择题。
AVL 判断失衡类型看离新结点最近的失衡结点，不是根。"中间值转上去"心法比背四种口诀可靠。
散列失败 ASL 的分母是模数 p，不是表长——2022 真题级别的陷阱。
线性探测容易"堆积"（非同义词抢同一个坑），拉链法没有堆积问题但需要额外指针空间——概念题常对比两者。

📝 章内练习（12 题 · 基础 → 提高 → 真题）

🟢 第一档 · 基础（4 题）

练习 1 · 考点：折半查找比较次数
对含 16 个元素的有序表进行折半查找，最多需要比较的次数是：
A. 4
B. 5
C. 6
D. 16
解析：选 B。最多比较次数 = 判定树高度 = ⌈log₂(n+1)⌉ = ⌈log₂17⌉ = 5。验证：2⁴=16 ≥ 17 不成立、2⁵=32 ≥ 17 成立，所以 5 层。
练习 2 · 考点：BST 性质
对二叉排序树进行中序遍历，得到的序列必然是：
A. 递增有序序列
B. 递减有序序列
C. 先序序列相同
D. 与插入顺序相同
解析：选 A。"左 < 根 < 右"递归成立 ⇒ 中序=左根右=从小到大。D 是经典错误：插入顺序只影响树形，不决定中序结果。这也是"验证一棵树是否为 BST"的标准手段。
练习 3 · 考点：线性探测
散列函数 H(key)=key%7，表长 7，依次插入 14、21、28（线性探测再散列），查找 28 需要比较的次数是：
A. 1
B. 2
C. 3
D. 4
解析：选 C。14%7=0 → 下标0；21%7=0 冲突 → 下标1；28%7=0 冲突 → 探下标1又冲突 → 下标2。查找 28 时也要从 H(28)=0 开始：比下标0（14，不等）、下标1（21，不等）、下标2（28，命中）——共 3 次。三个"同模数"挤成一串，正是线性探测的堆积现象。
练习 4 · 考点：AVL 旋转
在 AVL 树中，某结点的左孩子的左子树上插入新结点导致失衡（LL 型），应进行的调整是：
A. 左旋
B. 先左旋后右旋
C. 先右旋后左旋
D. 右旋
解析：选 D。LL 型（左边太重）→ 右旋；RR 型 → 左旋；LR/RL 型 → 两次对折。用"中间值转上去"验证：A 的左孩子 B 的左子树 L，三个候选中序为 L、B、A，中间值 B 是新根——正是 B 右旋上去。

🟡 第二档 · 提高（4 题）

练习 5 · 考点：ASL 的定义
ASL（平均查找长度）是：
A. 表长
B. 查找过程中关键字比较次数的期望值
C. 存储元素所需空间
D. 查找成功的概率
解析：选 B。ASL = Σ Pᵢ × Cᵢ，等概率下就是"平均要比较几次"——衡量查找算法好坏的唯一标尺，本章所有结构（折半、BST、AVL、散列）都在比它。
练习 6 · 考点：拉链法优点
与开放定址法（线性探测）相比，拉链法的优点是：
A. 非同义词不会聚集（无堆积现象），且删除结点方便
B. 不需要任何额外的空间
C. 可以不用散列函数
D. 装填因子必须小于 1
解析：选 A。拉链法同义词挂链、异义词各归各桶，无一次聚集；删除直接摘链即可。开放定址法删除只能打标记，物理删除会断链。B 错——拉链法需要额外的指针空间。
练习 7 · 考点：折半查找的前提
折半查找能够高效进行的前提是顺序表：
A. 元素互不相同
B. 元素个数是 2 的幂
C. 有序且顺序存储
D. 元素均匀分布
解析：选 C。两个前提缺一不可——链表无法 O(1) 取中点，无序则比大小失去意义。缺一个就是"不可用"，概念题钉子户。
练习 8 · 考点：5 阶 B 树的容量
5 阶 B 树中，除根外的任一非叶结点最多、最少各有多少棵子树？
A. 5、2
B. 5、3
C. 5、⌈5/2⌉=3
D. 4、2
解析：选 C。m 阶 B 树——最多 m 棵子树、非根非叶至少 ⌈m/2⌉ 棵；对应关键字数 = 子树数 − 1（最多 4 个、最少 2 个）。根最少 2 棵子树。口诀"顶天 m，立地 ⌈m/2⌉，根保底 2"。

🔴 第三档 · 真题（4 题 · 原题核对版）

练习 9 · 考点：散列 ASL 的影响因素
下列因素中，影响散列表（拉链法或开放定址法）平均查找长度的是：Ⅰ．散列函数的设计 Ⅱ．冲突处理策略 Ⅲ．装填因子 α
A. 仅Ⅰ
B. 仅Ⅲ
C. 仅Ⅱ、Ⅲ
D. Ⅰ、Ⅱ、Ⅲ
解析：选 D。三个因素全都影响 ASL；反直觉的结论是"ASL 与表中记录个数无直接关系"——由 α 统一刻画。2022 年原题考的辨析就是这组。
练习 10 · 考点：分块最优块长（2025 年真题·回忆版）
对含 400 个元素的索引顺序表（分块有序）进行分块查找，用顺序查找确定块（块内也用顺序查找），为使平均查找长度最小，每块的最佳长度是：
A. 10
B. 15
C. 20
D. 25
解析：选 C。ASL = (块数+1)/2 + (块长+1)/2，均值不等式在块长 = 块数 = √n 时最优：√400 = 20。此题来自 2025 年考生回忆版解析，数字以官方试卷为准。
练习 11 · 2015 年真题同型 · 考点：折半查找路径合法性
对有序表 (7, 14, 21, 35, 42, 56, 68) 进行折半查找（mid=⌊(low+high)/2⌋），下列比较序列中不可能出现的是：
A. 35, 21, 7
B. 35, 14
C. 35, 56
D. 35, 56, 68
解析：选 A。第一次比较必是 mid=35；若往左找，范围 [0,2] 的 mid=14——第二个比较值只能是 14，不可能是 21（21 在下一层才轮到）。B、C、D 依次是查找 14、56、68 的真实路径。方法：画出 7 结点判定树，A、B、C、D 就是四条路径，不在树上的就是答案。
练习 12 · 2012 年真题同型 · 考点：3 阶 B 树插入分裂
在 3 阶 B 树的某个终端结点（已含 2 个关键字）中插入新关键字后，该结点将：
A. 直接容纳 3 个关键字，无需调整
B. 分裂为两个结点，其中间关键字上移到父结点
C. 分裂为三个结点
D. 向兄弟结点"借"一个位置
解析：选 B。3 阶 B 树结点最多 2 个关键字，插入第 3 个触发分裂：按序排好后取中位关键字上移父结点，左右各留一个；父结点若因此超限则连锁分裂，最坏分裂到根、树高 +1。插入分裂与删除合并（借/并）是 B 树两大过程题，2012、2022 都考过删除版。
