第 6 章 · 排序

408 选择题的送分与坑王：算法思想都不难，但"快排第一趟结果""堆排序建堆后序列""哪些算法稳定"这些手工模拟题，不亲手画一遍必错。本章给你一个能逐步动画的排序实验室，模拟题不再靠脑补。

预计学习 3~5 小时 · 动画课堂 1 集 · 排序可视化实验室 1 个 · 练习 4 题 · 打卡 6 项

🎯 学习目标（学完你应该能）
① 手工模拟快排每一趟的 partition 过程（每趟至少归位一个枢轴）；
② 给定序列手工建大根堆并写出前两趟堆排序结果；
③ 默写八大排序的时间/空间复杂度和稳定性表；
④ 看到序列特征（基本有序 / 规模小 / 稳定性要求）能立刻选出最合适的算法。

6.1 先说人话：什么是稳定排序

🃏 生活类比
给一副已按花色分组的扑克按点数排序：稳定的算法保住"同点数的牌还在原花色组内"的相对次序；不稳定的会把组搅乱。考试里它决定了"能否多关键字排序"——先按次序排、再按主序排，靠稳定性传递。

稳定性：序列中两个相等的关键字，排序后相对次序不变则稳定。记忆口诀："插冒归基稳，快选希堆不稳"（直接插入、冒泡、归并、基数 稳定；快速、简单选择、希尔、堆排 不稳定）。

6.2 插入排序：像整理手牌

直接插入：左手是排好序的手牌，右手每次抓一张新牌，从右往左比着插进去。最好情况（已有序）只比较不移动 O(n)，最坏（逆序）O(n²)，序列基本有序时它最快。

希尔排序：先按增量 d 分组做插入排序（远距离搬运），逐步缩小 d 到 1。解决了直接插入"只能挪一步"的痛点，但不稳定，复杂度依赖增量序列（约 O(n^1.3)）。

6.3 交换排序：冒泡与快排

冒泡：相邻两两比较，大的往下沉，每趟把当前最大值"冒"到末尾。某趟无交换可提前结束——已有序时 O(n)，稳定。

快速排序（重中之重）：每趟选一个枢轴 pivot，用双指针把它甩到最终位置（左边都 ≤ 它、右边都 ≥ 它），再对两侧递归——分治。

int Partition(int a[], int low, int high) {
    int pivot = a[low];                // 默认取第一个为枢轴
    while (low < high) {
        while (low < high && a[high] >= pivot) high--;
        a[low] = a[high];              // 右边找到小的，甩到左边
        while (low < high && a[low] <= pivot) low++;
        a[high] = a[low];              // 左边找到大的，甩到右边
    }
    a[low] = pivot;                    // 枢轴归位
    return low;                        // 返回枢轴最终位置
}
📌 快排考点四连
① 每趟至少归位一个元素（枢轴）——判断"第 k 趟结果"的钥匙；② 平均 O(nlog₂n)，序列基本有序时反而退化到 O(n²)（划分极不均衡）；③ 空间 O(log₂n)（递归栈）；④ 不稳定（长距离交换会跨越相等元素）。

6.4 选择排序：最直观的"挑最小"

简单选择：每趟从未排序区挑最小值，与未排序区第一个交换。比较次数固定 n(n−1)/2，与初始状态无关；不稳定（交换跨越相等元素）。

堆排序：把数组看成一棵完全二叉树（第 3 章性质 5 回收：i 的孩子是 2i、2i+1）。建大根堆 → 堆顶（最大值）与堆底交换 → 堆规模减一 → 向下筛选恢复堆，循环 n−1 趟。

✅ 手工建堆心法
从最后一个非叶结点 ⌊n/2⌋ 开始，倒着逐个"向下筛选"：拿它和较大的孩子比，小了就换下去，换完继续往下查。建堆整体 O(n)；之后每趟筛选 O(log n)，总时间 O(nlog₂n)，空间 O(1)，不稳定。

6.5 归并排序与基数排序

2 路归并：两两合并有序段，k 个元素需要 ⌈log₂k⌉ 趟；每趟 O(n)，总 O(nlog₂n)，稳定，代价是需要 O(n) 辅助数组。"两个有序链表合并"是它的面试/大题常客。

基数排序：不比较！按个位、十位、百位依次"分发—回收"（桶）。d 位数、基数 r、n 个元素：O(d(n+r))，稳定，适合位数少、规模大的整数/字符串。

6.6 大总结表（默写级，考前必背）

算法最好最坏平均空间稳定性一句话特点
直接插入O(n)O(n²)O(n²)O(1)✅ 稳基本有序时最快
冒泡O(n)O(n²)O(n²)O(1)✅ 稳可提前终止
快速排序O(nlogn)O(n²) 有序时O(nlogn)O(logn)❌ 不稳平均最快的内部排序
简单选择O(n²)O(n²)O(n²)O(1)❌ 不稳比较次数与初态无关
堆排序O(nlogn)O(nlogn)O(nlogn)O(1)❌ 不稳最坏也快，空间最小
归并O(nlogn)O(nlogn)O(nlogn)O(n)✅ 稳要稳定+O(nlogn)只能选它

⚠️ 本章避坑清单

判断"第 k 趟结果"：快排每趟归位枢轴，冒泡/选择每趟归位一个最值，插入排序前 k 个是"局部有序"不是全局前 k 小——这是选择题最大的坑。
快排在"基本有序"序列上最慢（O(n²)），"随机/逆序"才发挥好；想让它对有序序列快，可随机选枢轴。
堆排序的"堆"是完全二叉树，用数组存时下标从 1 开始最顺手（2i/2i+1），别和 0 起点搞混。
归并趟数 = ⌈log₂n⌉：100 个元素 7 趟，不是 6。
要"稳定 + O(nlogn)"：内排只有归并；选择题问"最优"时先看稳定性要求再看复杂度。

📝 章内练习

练习 1 · 考点：快排一趟结果
对序列 {49, 38, 65, 97, 76, 13, 27} 以 49 为枢轴做一趟快速排序（Partition），结果是：
A. {27, 38, 13, 49, 76, 97, 65}
B. {13, 27, 38, 49, 65, 76, 97}
C. {27, 38, 13, 49, 65, 97, 76}
D. {13, 38, 27, 49, 76, 97, 65}
解析：选 A。双指针模拟：high 找到 27<49 甩到 low 位 → {27,38,65,97,76,13,49}；low 找到 65>49 甩到 high 位；high 找到 13<49 甩到 low 位；low 找到 97>49 甩到 high 位；两指针在原 49 位置相遇，49 归位。左边 {27,38,13} 都 ≤49，右边 {76,97,65} 都 ≥49，但两侧内部未排好——B 是排序完成的最终结果，别偷懒直接写终局。
练习 2 · 考点：稳定性
下列排序算法中，稳定的是：
A. 快速排序
B. 堆排序
C. 归并排序
D. 简单选择排序
解析：选 C。口诀"插冒归基稳，快选希堆不稳"。归并只在两段之间合并，相等元素先取左边段，天然稳定；快排/选择/堆排的长距离交换都会跨越相等元素破坏次序。
练习 3 · 考点：初态敏感性
待排序序列基本有序（接近正序），要求时间复杂度接近 O(n)，最合适的算法是：
A. 快速排序
B. 直接插入排序
C. 堆排序
D. 简单选择排序
解析：选 B。直接插入和冒泡在正序时每趟只比较一次不移动，O(n)；快排在正序时枢轴每次划分出"一边全空"，退化 O(n²)——"快排最怕有序序列"是高频结论。堆排/选择排序的比较次数与初态无关，永远 O(nlogn)/O(n²)。
练习 4 · 考点：堆的判别
下列序列中，是大根堆的是：
A. {91, 85, 73, 96, 64, 52}
B. {91, 85, 73, 64, 96, 52}
C. {16, 72, 53, 85, 90, 91}
D. {96, 85, 73, 64, 52, 16}
解析：选 D。大根堆要求 a[i] ≥ a[2i] 且 a[i] ≥ a[2i+1]。D：96≥{85,73}，85≥{64,52}，73≥16 ✓。A 里 85 的孩子有 96（85<96）✗；B 同理 85 的孩子 96 ✗；C 是小根堆特征。画成完全二叉树逐对检查最保险。
