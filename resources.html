📚 书籍精读导航（按定位分层选读）

书不在多，在于每本解决一个特定问题。下表按"定位"分组：入门书建画面感、应试书对齐真题、严谨书补证明、视角书串体系。加 ⭐ 的是本站章节里直接引用过讲法的书。

📗

严蔚敏《数据结构（C语言版）》 ⭐ 官方基准

408 大纲的事实基准，定义与算法描述都是"考试语言"。特点：静态链表、十字链表、败者树等独有结构，别处看不到。用法：当定义与术语的裁判，说法有分歧时以它为准。

定位：严谨 / 官方参考 · 本站第 1、2、6 章深挖引用
📘

王道《数据结构考研复习指导》 ⭐ 应试主力

与真题一一对应，考点星级标注 + "温馨提示/易错点"栏目，课后题质量高。用法：一轮主干教材，每题做完标记年份，直接形成考点热力图。

定位：应试 · 一轮主力 · 本站"真题怎么考"框的规律来源
🐍

《Hello 算法》（krahets，开源免费） ⭐ 本站引用最多

动画图解 + 多语言可运行代码。独有讲法：栈是"被屏蔽掉部分操作的数组/链表"、DFS 像绕树外围走一圈（每个结点经过三次，前中后序是第 1/2/3 次记录）、层序队列最长为 (n+1)/2、冲突不可避免的鸽巢论证。GitHub 仓库 krahets/hello-algo 提供 PDF/EPUB。

定位：图解 / 入门 · 合法免费（官网 + GitHub Release）
🧭

邓俊辉《数据结构（C++版）》（清华） ⭐ 视角最佳

把数据结构按访问方式分成四类：循秩（向量）、循位置（列表）、循值（散列）、循关键码（BST）。还有"3+4 重构"（四种失衡是一次手术）、二分查找三版本、Fibonacci 查找的代价不对称。用法：二轮串体系时读绪论与对应章。

定位：视角 / 进阶 · 作者官网有课程与讲义资源
⚙️

Sedgewick《算法（第 4 版）》 ⭐ 设计动机

讲"为什么这样设计"：2-3 树→红黑树的编码关系、散列探测的期望公式（命中 ½(1+1/(1−α))、失败 ½(1+1/(1−α)²)）、堆的精确比较次数常数、自底向下沉建堆是线性时间。官网提供全书讲义与代码。

定位：进阶 · 合法免费在线讲义 algs4.cs.princeton.edu
🧮

CLRS《算法导论》 ⭐ 证明标准

决策树下界（n! 种排列 ⇒ Ω(n log n)）、摊还分析的三种方法（聚合/核算/势能）的唯一标准表述。用法：不要通读，只查这三处，够写三年真题的复杂度论证。

定位：严谨 · 查证用，非通读材料
🏕️

OI Wiki（信息学竞赛知识库） ⭐ 边界与证明

并查集的 α(n) 均摊分析、单调队列"弹出是唯一删除理由"、前缀函数 π 与 next 的对应、border 与最小周期。中文、免费、开源。用法：408 冲高分与"想知其所以然"时查。

定位：严谨 / 竞赛级 · 合法免费 oi-wiki.org
🎈

程杰《大话数据结构》

生活类比密度最高的一本，适合零基础先建立"画面感"（本站的生活类比框与它同一路数，但讲法已重写）。缺点：严谨度不足，不能当唯一教材。

定位：通俗 / 入门 · 只作入门过渡，不作复习主线
🖊️

胡凡《算法笔记》

按题型专题讲模板套路，代码逐行注释，主打上机编码能力。零基础过渡到 C 实现的最佳跳板（本站备考页推荐的第一站）。

定位：入门 / 上机 · 跨考补 C 语言与代码手感
🔧

Weiss《数据结构与算法分析（C 语言版）》

对摊还、优先队列、散列的工程化分析比考研书细，适合想搞懂"为什么 O(1) 均摊"这类问题的同学。

定位：进阶 · 补摊还分析的工程视角
🗂️

CS-Notes（GitHub 开源） / TheAlgorithms

前者适合刷题期速查算法模板，后者可按 DIRECTORY.md 查同一结构的多种写法。两者都不是 408 系统教材，只作代码参考。

定位：速查 / 代码参考 · GitHub 开源
🎬

algorithm-visualizer

把你写的代码喂进去，实时可视化它怎么跑。适合"写完算法想看看每一步在干什么"的时候，与本站实验室互补。

定位：工具 · 在线，配合自己写的代码使用

重复复习法

上岸经验贴高频结论："408 最重要的就是重复"——同一知识点间隔一天、三天、七天各复习一次，把重复投资放在早期远比后期焦虑划算。本站打卡清单与错题本都按这个思路设计。
