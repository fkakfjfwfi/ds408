第 2 章 · 栈、队列和数组

两种「被限制」的线性表：栈只准从一头进出，队列一头进一头出。限制反而造就了它们各自的杀手级应用。408 对本章的循环队列判满判空几乎年年必考。

预计学习 3~4 小时 · 动画课堂 1 集 · 练习 12 题 · 打卡 6 项

本页导航学习目标栈括号与表达式队列循环队列矩阵压缩进阶深挖动画课堂避坑清单章内练习打卡
🎯 学习目标（学完你应该能）
① 看到一个入栈/出栈混合序列，判断它是不是合法的出栈序列；
② 用栈手工演算括号匹配和中缀转后缀；
③ 画出循环队列入队/出队时 front、rear 的移动，默写三种判满判空方案；
④ 写出对称矩阵按行优先压缩存储的下标映射公式。

2.1 栈：羽毛球筒

🏸 生活类比
栈就是一个羽毛球筒：球只能从筒口塞进去、从筒口拿出来。最先塞进去的球被压在最底下，最后才能拿出来——后进先出 LIFO（Last In First Out）。装球 = 入栈 push，取球 = 出栈 pop，筒口那端叫栈顶 top。

栈是只允许在一端进行插入和删除的线性表。允许操作的一端叫栈顶，另一端叫栈底。三个基本操作：push（入栈）、pop（出栈）、peek/getTop（读栈顶不出栈）。

📌 408 高频考点：卡特兰数
n 个不同元素依次进栈，合法的出栈序列共有 C₍₂ₙₙ₎ / (n+1) 种（卡特兰数）。n=3 时是 5 种。真题常问"以下哪个序列不可能"——判断方法：任何元素出栈时，比它晚进栈的元素必须先出完（或模拟一个栈走一遍）。
🔬 实验室：栈的 push / pop
点按钮操作栈，注意栈顶指针 top 的变化。容量 6，满了再 push 会怎样？空了再 pop 会怎样？——亲手触发一次"上溢/下溢"。
栈顶指针 top 指向当前栈顶元素。

2.2 栈的应用：括号匹配与表达式求值

括号匹配：从左到右扫描，左括号入栈；遇到右括号就弹出一个栈顶的左括号配对。三种失败情形：右括号来了栈空（缺左）、扫描完栈非空（缺右）、弹出的类型不匹配（交叉）。

表达式求值：中缀表达式（如 3+4×2）机器处理不方便，常转成后缀表达式（3 4 2 × +）用栈求值——操作数直接入栈，遇运算符就弹两个数计算再压回。408 选择题爱考"后缀表达式求值过程中栈的最大深度"。

✅ 中缀转后缀速记
操作数直接输出；运算符入栈前，先把栈里优先级 ≥ 自己的运算符全部弹出输出；左括号直接入栈当保护罩，右括号来了弹到左括号为止。例：A+B×(C−D) → A B C D − × +。

第三个应用：递归。函数调用本质就是栈——每层调用压一个栈帧（参数、局部变量、返回地址），递归太深会栈溢出。第 3 章树的遍历就是递归的最好练习场。

2.3 队列：排队买奶茶

🧋 生活类比
队列就是奶茶店排队：新来的排到队尾，店员从队头叫号。先来的先喝到——先进先出 FIFO。入队在队尾 rear，出队在队头 front。

用数组实现的队列有个坑：出队时 front 一直前移，数组前半段就空出来了，但 rear 已到数组尽头没法入队——明明还有空位却报"队满"，这叫假溢出。

2.4 循环队列：传送带与取模魔法

🍕 生活类比
解决假溢出的办法：把数组首尾接起来，变成回转寿司传送带。指针走到尽头就绕回起点，数学上一行代码搞定：rear = (rear + 1) % MaxSize。
📌 408 必考：判满判空三大方案（默写级）
方案判空判满元素个数
① 牺牲一格front == rear(rear+1) % MaxSize == front(rear−front+MaxSize) % MaxSize
② 增设 size 变量size == 0size == MaxSizesize
③ 增设 tag 标志tag==0 且 front==reartag==1 且 front==rear—
记忆锚点：方案①入队后 tag 置 1、出队后置 0——最近一次操作决定了相等时是满还是空。tag 方案不牺牲存储单元，这是它相对方案①的优势，真题爱对比这两者。
🔬 实验室：循环队列（牺牲一格方案）
容量 6，牺牲一格判满。入队看 rear 取模绕圈，出队看 front 追赶。试着把队列塞满，体会"满队时 rear 后面那格永远空着"。
front = 0，rear = 0，空队。front 指向队头元素，rear 指向下一入队位置。

2.5 特殊矩阵的压缩存储（进阶）

对称矩阵只存下三角（含对角线）：aᵢⱼ（i≥j）按行优先存进一维数组，前面共有 1+2+…+(i−1) 个元素，映射公式：

下三角（i ≥ j）：k = i(i−1)/2 + j − 1        // 数组下标从 0 起
上三角（i ≤ j）取转置对称性即可：a[i][j] = a[j][i]
三对角矩阵：k = 2i + j − 3（第一行和最后一行单算）
⚠️ 公式记法不靠背
别硬背！考场用"数前面有几行"推导：aᵢⱼ 之前有 i−1 个完整行，共 i(i−1)/2 个元素，再加上本行前面的 j−1 个。推导一遍比背十遍牢固。

🚀 进阶深挖（教材级）

对齐严蔚敏教材与王道复习指导的处理深度，二轮复习必看。

深挖 1 · 栈顶指针的两种约定（王道反复强调的坑）

约定初始化判空判满进栈出栈
top 指向栈顶元素top = −1top == −1top == MaxSize−1先移针再放数 S[++top]=x先取数再移针 x=S[top--]
top 指向栈顶上一空位top = 0top == 0top == MaxSize先放数再移针 S[top++]=x先移针再取数 x=S[--top]

天勤口诀：「−1 约定先动针，0 约定先动数」。题目不给约定就问——两种约定的答案完全不同，这是命题人最爱埋的暗雷。

深挖 2 · 共享栈：一个数组养两个栈

两个栈共用一段空间，栈顶相向而立：栈 1 的底在数组左端（top1 从 −1 增），栈 2 的底在右端（top2 从 MaxSize 减）。栈满条件只有一个：top1 + 1 == top2（两栈顶相逢）。它存在的意义：两个栈的需求此消彼长时，共享空间比各分一半更抗溢出——这是简答题的常客。

深挖 3 · 表达式求值的完整算法（代码级）

// 中缀 → 后缀：操作数直接输出；运算符弹栈输出所有优先级 ≥ 自己的；左括号当保护罩
// 后缀求值：遇数入栈；遇运算符弹两次（先弹的是右操作数！），算完压回
int calc(int a, int b, char op) {           // 注意操作数顺序
    switch (op) {
        case '+': return a + b;  case '-': return a - b;   // a(先弹者?不:次弹)在前
        case '*': return a * b;  case '/': return a / b;
    }
}
// 大题高频扣分点：减法/除法的操作数顺序 —— 第二个弹出的是左操作数

选择题衍生考法：「后缀表达式求值过程中栈的最大深度」——逐 token 模拟一遍，顺手记录峰值即可，别脑算。

深挖 4 · 特殊矩阵与稀疏矩阵：从公式到结构

对称矩阵下三角按行优先存一维数组 s（下标从 0 起，a₁₁ 存 s[0]）：aᵢⱼ(i≥j) 之前有 i−1 个完整行，共 i(i−1)/2 个元素，再加本行 j−1 个，故 k = i(i−1)/2 + j − 1（a[i][j] 存于 s[k]）。考场别背，现推：数"前面有几行"。

三元组表 (行, 列, 值) 只存非零元，按行序排列；十字链表再给每个非零元挂右指针（同行下一个）和下指针（同列下一个），行列各成一条链——严书为"矩阵加减时非零元位置频繁变化"设计的结构，考概念辨析（选择题问"稀疏矩阵用三元组/十字链表存取某元素的时间"）。

📌 真题怎么考（本章规律）
出栈序列是超高频考点：2009 考栈容量反推（进栈出栈交错进队列）、2010 考带约束的不可能序列、2011 考指定开头序列计数、2013 考位置元素取值个数——一套"模拟法"通吃：开一个栈老老实实模拟。循环队列年年变体：个数公式、判满判空、牺牲格方案；2015 年还考过"队列用数组实现时的假溢出"。卡特兰数 2010~2014 隔年一考，记 n=3→5、n=4→14 即可现场用。

⚠️ 本章避坑清单

栈顶指针的约定先看清：top 指向栈顶元素还是下一个空位，两种约定下判空判满、push/pop 的顺序都不同，题目会明说，别想当然。
出栈序列合法性判断：直接开一个栈模拟，别凭感觉。n=4 时就有 14 种合法序列，人脑枚举必错。
循环队列元素个数公式 (rear−front+MaxSize) % MaxSize 的 +MaxSize 是防负数，减法结果为负时取模才正确。
"队满时牺牲一格方案"能存 MaxSize−1 个元素，题目问"最多能存几个"时减一。
队列的应用场景背三个：缓冲区（生产者消费者）、BFS、页面置换 FIFO——后面章节还会反复遇到。

📝 章内练习（12 题 · 基础 → 提高 → 真题）

🟢 第一档 · 基础（4 题）

练习 1 · 考点：出栈序列合法性
入栈顺序为 1,2,3,4，且进栈、出栈可交错进行，则不可能的出栈序列是：
A. 1,2,3,4
B. 4,1,2,3
C. 3,2,4,1
D. 2,1,4,3
解析：选 B。模拟法：要让 4 先出，1、2、3 必须都已压在栈里（从底到顶 1,2,3）。4 出栈后栈顶是 3，下一步只能出 3，不可能出 1。A 全进全出；C 出3（1,2在栈）→出2→进4出4→出1 ✓；D 进1进2，出2出1，进3进4，出4出3 ✓。
练习 2 · 考点：卡特兰数
4 个不同元素依次进栈，得到的出栈序列种数是：
A. 16
B. 14
C. 14（卡特兰数 C₈₄/5 = 14）
D. 24
解析：选 C。卡特兰数公式 C₍₂ₙₙ₎/(n+1)：n=4 时 C(8,4)/5 = 70/5 = 14。D 的 24 是 4! 全排列数——它把不合法的序列也算进去了。记几个常用值：n=3→5，n=4→14，n=5→42。
练习 3 · 考点：循环队列判满
循环队列容量 MaxSize=7（牺牲一格方案），front=5，rear=3，则队列中的元素个数是：
A. 5
B. −2
C. 2
D. 6
解析：选 A。(rear−front+MaxSize) % MaxSize = (3−5+7) % 7 = 5。C 是忘加 MaxSize 直接相减的陷阱；rear 绕圈超过 front 时就得靠 +MaxSize 把负数拉回正区间。
练习 4 · 考点：中缀转后缀
中缀表达式 (A+B)×C−D 的等价后缀表达式是：
A. A B + C × D −
B. A B C × + D −
C. − × + A B C D
D. A B + C × D −（同 A）
解析：选 A（D 为排版重复项）。括号内 A B + 先出，× 与左边的 C 结合输出 C ×，最后减号优先级最低最后输出。B 错在 × 抢在 + 前面输出，违反了括号优先级；C 是前缀表达式不是后缀。

🟡 第二档 · 提高（4 题）

练习 5 · 考点：循环队列取模的作用
循环队列入队时执行 rear = (rear + 1) % MaxSize，其中"取模"运算的根本作用是：
A. 防止 rear 溢出为负数
B. 让 rear 走到数组末尾后自动绕回 0，复用前面出队空出的空间
C. 判断队列是否已满
D. 计算队列中的元素个数
解析：选 B。取模 = "走到尽头就绕回起点"，消灭的是普通数组队列的假溢出（前半段空着但 rear 到顶没法入队）。C、D 各有对应写法（判满用 front 比较、个数用差值取模），但"取模"本身的使命就是绕圈复用。
练习 6 · 考点：共享栈
两个栈共享一个大小为 MaxSize 的数组空间，栈顶相向设置（栈 1 栈底在左、栈 2 栈底在右），top1、top2 分别为两栈栈顶指针（约定 top1 = −1、top2 = MaxSize 为空）。栈满的判定条件是：
A. top1 + top2 == MaxSize
B. top1 == top2
C. top1 + 1 == top2
D. top1 - 1 == top2
解析：选 C。两栈顶相向增长，top1 右移、top2 左移；当 top1 的上一格就是 top2 时再压任何一个都越界——这就是"相逢"。共享栈的意义：两栈空间需求互补时，比各分一半 MaxSize/2 更抗溢出，简答题常考它的优缺点对比。
练习 7 · 考点：栈顶指针约定（top=0 型）
顺序栈采用"top 指向栈顶元素的下一个空位"的约定（初始 top = 0），正确的出栈操作是：
A. x = S[top]; top--;
B. top--; x = S[top];
C. x = S[--top];（无需判空）
D. 若 top > 0，则执行 top--; x = S[top];
解析：选 D。top=0 约定下栈顶元素在 S[top−1]，所以先移针再取数——口诀"0 约定先动数？不：0 约定出栈先动针"（进栈先放数后动针 S[top++]=x，出栈先动针后取数 x=S[--top]）。B 单看赋值正确但漏了判空：top=0 时会读到 S[−1] 越界。A 是 top=−1 约定的写法，两种约定千万别混。
练习 8 · 考点：对称矩阵压缩存储
将 10 阶对称矩阵 A 的下三角部分（含对角线）按行优先压缩存入一维数组 s（s[0] 存 a₁₁），则 a₈₅ 在 s 中的下标是：
A. 31
B. 32
C. 33
D. 35
解析：选 B。考场现推：a₈₅ 之前有 7 个完整行，共 1+2+…+7 = 28 个；本行 a₈₁~a₈₄ 在它前面，又 4 个；合计 32 个，下标 = 32（下标从 0 起）。公式 k = i(i−1)/2 + j − 1 = 28 + 4 = 32。A 忘加本行前面的元素、C 多加一格——"数前面有几行"永远比背公式稳。

🔴 第三档 · 真题（4 题 · 原题核对版）

练习 9 · 考点：栈容量反推
为解决计算机主机与打印机之间速度不匹配问题，通常设置一个打印数据缓冲区，主机把要打印输出的数据依次写入该缓冲区，打印机依次从该缓冲区取出数据。该缓冲区的逻辑结构应该是：（2009 年原题为缓冲区 + 栈队列辨析）下列说法正确的是：
A. 必须是队列——先写入的先打印，符合先进先出
B. 必须是栈——后写入的先打印
C. 是队列——缓冲区"依次写入、依次取出"，顺序不能颠倒
D. 是树形结构——打印任务有优先级
解析：选 C。2009 年原题问"缓冲区的逻辑结构"，答案即队列（FIFO 保证打印次序与提交次序一致）。记忆锚点：凡是"排队、依次、不能插队"的场景选队列；凡是"最近、撤销、回头"的场景选栈。
练习 10 · 考点：栈容量反推
元素 a、b、c、d、e、f 依次进栈（进栈和出栈可交替进行），出栈后立即进入队列并得到出队序列 b、d、c、f、e、a。则栈的最小容量是：
A. 2
B. 3 需要专门证明，不行
C. 3
D. 4
解析：选 C。逐字符模拟并记录栈深峰值：要出 b → 先压 a、压 b（栈深2）弹出 b；要出 d → 压 c、压 d（栈深3）弹出 d；出 c（栈剩a）；出 f → 压 e、压 f（栈深3）弹 f；出 e；出 a。峰值 3，故最小容量 3。方法：目标序列倒着逼出来的压栈过程，峰深就是答案。
练习 11 · 考点：带约束的出栈序列
元素 a、b、c、d、e 依次进栈，且不允许连续三次退栈（即连续出栈操作最多进行两次，中间必须插入进栈动作），则不可能得到的出栈序列是：
A. c e d b a
B. b c a e d
C. a b c d e
D. a f e d c b（含未入栈元素 f）
解析：选 D。D 的第一个出栈元素是 f——f 根本不在进栈序列里，直接出局（这是 2010 年原题的 D 选项设定，考的是审题）。A、B、C 用"压栈-弹栈逐位模拟 + 记录连续弹栈次数"验证均可行。本题教两件事：先查元素集合合法性，再做模拟。
练习 12 · 考点：指定开头的出栈序列计数
元素 a、b、c、d、e 依次进栈（进栈出栈可交错），以 d 开头的出栈序列共有多少种？
A. 3
B. 4
C. 5
D. 6
解析：选 B。d 出栈时，a、b、c 必已压在栈中（栈内从底到顶 a,b,c），e 尚未进栈。d 出栈后，剩下 {a,b,c,e} 交替进出栈：e 随时可以插入到 a、b、c 的出栈序列的任何"间隙"中，a、b、c 的合法出栈顺序只有 c,b,a 一种（栈内已定）。e 可出现在 4 个位置（c 前 / c 后 / b 后 / a 后）→ 共 4 种：d e c b a、d c e b a、d c b e a、d c b a e。规律：固定某元素先出 = 栈内已堆成定序 + 未进栈元素插空。
