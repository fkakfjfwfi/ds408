🎯 学习目标（学完你应该能）
① 手工模拟朴素模式匹配（BF），说出主串指针为什么要回溯、最坏比较多少次；
② 对任意模式串手工计算 next 数组（408 默认 next[1]=0、next[2]=1 的约定）；
③ 由 next 推出改进的 nextval，并解释它省掉了哪些无用比较；
④ 默写 KMP 的复杂度 O(n+m)，并解释主串指针为什么可以不回溯。

7.1 先说人话：什么是串

🔍 生活类比
串就是字符串——内容被限制成"字符"的线性表。Ctrl+F 在文档里找关键词，就是在做"模式匹配"：文档是主串，关键词是模式串。

术语三件套：串中任意个连续字符组成子串（空串也是任何串的子串）；字符在串中的位序从 1 开始（408 与严蔚敏教材约定）；子串在主串中的位置 = 子串第一个字符的位序。存储有定长顺序存储、堆分配存储、块链存储三种，408 只考概念级别。

7.2 朴素模式匹配 BF：笨办法

主串指针 i、模式串指针 j 从头开始，逐字符对齐比较；
匹配成功则一起后移；失配则 i 回溯到"本轮起点的下一个"（i = i − j + 2），j 归 1 重来；
最坏情形：每个起点都比对到最后一个字符才失败，约 (n−m+1)×m 次，时间 O(n×m)。
⚠️ BF 的浪费在哪
已经比对过的信息全被扔掉了！主串前 5 个字符明明都看过了，失配后却要退回去从第 2 个字符重新看。KMP 的全部智慧就是：主串指针 i 永不回溯，失配后只动模式串。

7.3 KMP：模式串自己会滑

失配时，模式串已经匹配过的部分 T[1..j−1] 是已知的。如果它有相等的前缀和后缀（比如 'abaab' 的前缀 'ab' = 后缀 'ab'），那么主串里刚匹配过的后缀就等于模式串的前缀——模式串可以直接滑到"前缀对齐后缀"的位置继续比，i 一步都不用退。

每个位置 j 滑多远，取决于 T[1..j−1] 的最长相等前后缀长度 + 1——这就是 next[j]。

📌 next 数组手算四步（408 默认约定）
① next[1] = 0；② next[2] = 1（只有一个字符，无真前后缀）；③ 对 j≥3：看 T[1..j−1] 的最长相等真前后缀长度 k，next[j] = k + 1；④ 失配时 j 跳到 next[j]（next[j]=0 时 i、j 都 +1）。口诀：看前串，数前后缀，加一填表。
// 模式串 'abaabc' 的 next 数组（1 起始约定）
//  j:    1  2  3  4  5  6
//  T[j]: a  b  a  a  b  c
//  next: 0  1  1  2  2  3
// 例：next[4]：看 'aba' → 前缀 'a' = 后缀 'a' → 长度1 → next[4]=1+1=2
// 例：next[6]：看 'abaab' → 前缀 'ab' = 后缀 'ab' → 长度2 → next[6]=2+1=3

7.4 nextval：把"明知必败"的比较也省掉

next 还有一处浪费：失配后 j 跳到 next[j]，但如果 T[next[j]] 和 T[j] 是同一个字符，那这次比较必然又失败。nextval 的规则：

if (T[j] == T[next[j]])  nextval[j] = nextval[next[j]];  // 跳过的比较直接继承
else                     nextval[j] = next[j];
✅ 一句话区分
next 答"跳到哪"，nextval 答"跳过明知会失败的，直接跳到真正可能有戏的位置"。两者都只动 j，主串 i 永不回溯——KMP 复杂度 O(n+m) 的来源。
🔬 实验室：next 数组计算 + KMP 匹配动画
输入模式串点"计算 next"，逐列看最长相等前后缀怎么数；点"播放匹配"看主串 i 永不回溯、模式串 j 滑动的全过程。
主串固定为 S = abaababaabaabc（长度 14）。先算 next，再播放匹配。

🚀 进阶深挖（教材级）

对齐严蔚敏教材的 next/nextval 体系，含手算五步法。

深挖 1 · 串的存储三件套（概念题预备）

定长顺序存储（Static String，截断风险）、堆分配存储（Heap String，malloc 动态扩容，408 默认）、块链存储（每结点存多个字符，"块大小 × 密度"决定效率）。位序从 1 数起；子串位置 = 子串首字符在主串中的位序；空串长度 0、空格串长度是空格数——两组概念年年有人混。

深挖 2 · next 手算五步法（30 秒一列）

next[1] = 0，next[2] = 1（408 约定，直接写）；
对位序 j ≥ 3，把 T[1..j−1] 抄在草稿上（不含 T[j] 自己！）；
找该子串的"最长相等真前后缀"长度 k（真前后缀 = 不能是整个子串）；
next[j] = k + 1；
全表填完后，抽查一列做"回归测试"。
// 模式串 'abaab' 的 next（考场演示）
// j:     1  2  3  4  5
// T[j]:  a  b  a  a  b
// 看:       a  ab  aba  abaa
// 最长相等前后缀: —  —  a(1)  a(1)  ab(2)
// next:  0  1  1  2  2

深挖 3 · nextval 的推导表（两栏对照法）

nextval 逐位由 next 推出，两栏对照一次算完：若 T[j] == T[next[j]]，则 nextval[j] = nextval[next[j]]；否则 nextval[j] = next[j]。直觉：跳到 next[j] 位置后还要比 T[next[j]] 与主串——如果它和 T[j] 长得一样，那一跳必然还是失败，所以"继承跳板的答案"。'abaabc' 的 next=0 1 1 2 2 3，nextval=0 1 0 2 1 3。

📌 真题怎么考（本章规律）
408 对串的选择题集中在三个动作：算 next、算 nextval、数比较次数/分析复杂度（BF 最好 n−m+1 次、最坏 (n−m+1)×m；KMP 严格 O(n+m)）。主串指针不回溯是 KMP 的一切：i 单调前进最多 n 次，j 的上滑（匹配成功 +1）最多 m 次，下滑总量被上滑总量封顶——摊销出 O(m)。2015 年前后多次以"变体模式串"重考同一套路。
🌐 多源视角（不同书的讲法）
  • 【OI Wiki · 前缀函数】：π[i] = 子串 s[0..i] 的最长相等真前缀/真后缀长度，π[0]=0。408 的 next[j] 只是它的错位版（整体右移一位后 +1）。读懂这句，就不必在"π 数组 / next / nextval"之间来回换算。
  • 【势能与复杂度】：失配时 j ← π[j−1] 反复回退，但相邻 π 值至多 +1，故总回退次数与总前进次数同阶 ⇒ 求 next 是 O(m)、匹配是 O(n+m)。这解决了"看着像 O(nm) 却说是 O(n+m)"的困惑。
  • 【border 与周期】：存在长为 r 的 border（相等真前后缀）⇔ |s|−r 是周期；π[n−1] 是最长 border ⇒ n−π[n−1] 是最小周期。可用于"循环节 / 最小重复单元"类判断题，本站练习 16 就是它。
  • 【前缀函数是在线算法】：可边读字符边算，只需保留前 M+1 个字符；顺带说明"next 只依赖模式串自身，预处理与主串无关"——这是 KMP 能离线预处理的根本。
  • 【BF 最坏的真实构造】：主串 aaa…a、模式 aaa…b——每趟都比到最后一个字符才失配，这才是 O(nm) 的实证，而不是一句"最坏 O(nm)"。
参考：OI Wiki oi-wiki.org/string/kmp/；严蔚敏《数据结构（C语言版）》4.3

⚠️ 本章避坑清单

next 数组的下标约定看教材：严蔚敏/408 用 1 起始且 next[1]=0；有些资料用 0 起始且 next[0]=−1。答题前先确认题目约定，两者差 1 别背串。
算 next[j] 只看 T[1..j−1]，不包括 T[j] 自己——最容易犯的错。
"最长相等前后缀"不许是整个串本身（真前后缀），否则永远等于自己，没有意义。
KMP 主串指针不回溯 ≠ 主串不走回头路视觉上——动画里 i 始终单调右移，j 才会跳动。
复杂度：BF 最坏 O(n×m)，KMP 严格 O(n+m)——"KMP 提高的是最坏性能，很多实际文本中 BF 也不慢"是概念题的正解说法。

📝 章内练习（16 题 · 基础 → 提高 → 真题）

🟢 第一档 · 基础（4 题）

练习 1 · 考点：next 数组手算
模式串 'abaabc'（位序从 1 开始）的 next 数组是：
A. 0 1 1 1 2 2
B. 0 1 2 2 3 1
C. 0 1 1 2 2 3
D. 1 1 2 2 3 3
解析：选 C。逐列数：j=3 看 'ab' 无相等真前后缀 → 1；j=4 看 'aba'，前缀'a'=后缀'a' 长 1 → 2；j=5 看 'abaa'，最长 'a' → 2；j=6 看 'abaab'，'ab'='ab' 长 2 → 3。口诀"看前串，数前后缀，加一填表"。去实验室输入 abaabc 验证一遍。
练习 2 · 考点：KMP 复杂度本质
KMP 算法的时间复杂度为 O(n+m)，其根本原因是：
A. 模式串更短
B. 主串指针 i 不回溯，j 的滑动总移动量摊销后为 O(m)
C. 用了哈希表加速字符比较
D. 递归代替了循环
解析：选 B。i 单调右移最多 n 次；j 虽会跳动，但每次匹配成功 j+1 最多 m 次，失配下滑总量不会超过上滑总量（摊销），总共 O(m)。两次线性扫描 → O(n+m)。KMP 和哈希、递归都没关系。
练习 3 · 考点：BF 最坏情形
主串长 n、模式串长 m（n≫m），朴素模式匹配算法在最坏情况下的时间复杂度是：
A. O(n×m)
B. O(n+m)
C. O(log(n+m))
D. O(n²)
解析：选 A。最坏：如主串 'aaaa…a' 找 'aaab'，每个起点都要比对到模式串最后一个字符才失败，约 (n−m+1)×m 次。B 是 KMP 的成绩，D 忽略了 m——n×m 在 n≈m 时才退化成 n²。
练习 4 · 考点：nextval 手算
模式串 'abaabc' 的 nextval 数组是：
A. 0 1 1 2 2 3
B. 0 0 1 2 2 3
C. 0 1 0 2 2 3
D. 0 1 0 2 1 3
解析：选 D。在 next（0 1 1 2 2 3）基础上逐位检查：j=3：T[3]='a' 与 T[next[3]]=T[1]='a' 相同 → nextval[3]=nextval[1]=0；j=5：T[5]='b' 与 T[next[5]]=T[2]='b' 相同 → nextval[5]=nextval[2]=1。其余位字符不同，直接继承 next。口诀："与跳往位置的字符相同？那这一跳也是白跳，跟着它一起跳。"

🟡 第二档 · 提高（4 题）

练习 5 · 考点：子串与位序
串 'datastructure' 中子串 'struct' 的位置（位序从 1 开始）是：
A. 4
B. 5
C. 6
D. 7
解析：选 B。逐个数：d(1) a(2) t(3) a(4) s(5) t(6) r(7)…，'struct' 首字符 s 在位序 5，故位置为 5。注意"子串位置 = 首字符位序"这一条，别数成尾部。
练习 6 · 考点：空串与空格串
关于空串和空格串，说法正确的是：
A. 空串长度为 0，空格串长度为其所含空格个数
B. 空串就是空格串
C. 空格串长度为 0
D. 两者都是不存在的串
解析：选 A。空串 "" 长度 0；空格串 " " 长度 = 空格个数（如 3）。概念辨析题，一字之差。
练习 7 · 考点：'abaab' 的 next
模式串 'abaab' 的 next 数组是：
A. 0 1 1 1 2
B. 0 1 1 2 2
C. 0 1 2 2 3
D. 0 1 1 2 3
解析：选 B。j=3 看 'ab' 无相等真前后缀 → 1；j=4 看 'aba'，'a'='a' 长 1 → 2；j=5 看 'abaa'，'a'='a' → 2。深挖 2 的五步法走一遍即可。
练习 8 · 考点：nextval 判别
已知某模式串中 T[j] = 'b'，且 next[j] 所指位置的字符 T[next[j]] 也为 'b'，则 nextval[j] 等于：
A. next[j]
B. j
C. 1
D. nextval[next[j]]
解析：选 D。跳到 next[j] 后要比较的字符与 T[j] 相同 → 这次比较必然再失败 → 直接继承跳板的答案。这就是"把明知会失败的比较也跳过"的规则本体。

🔴 第三档 · 真题（8 题 · 原题核对版）

练习 9 · 真题同型·高频 · 考点：'aabbaab' 的 next
模式串 'aabbaab' 的 next 数组是：
A. 0 1 2 1 1 2 3
B. 0 1 1 2 1 2 3
C. 0 1 2 1 1 2 2
D. 0 1 2 2 1 2 3
解析：选 A。逐列：j=2 → 1；j=3 看 'aa'，'a'='a' → 2；j=4 看 'aab' 无 → 1；j=5 看 'aabb' 无 → 1；j=6 看 'aabba'，首尾 'a'='a' → 2；j=7 看 'aabbaa'，最长相等真前后缀 'aa' 长 2 → 3。故 next = 0 1 2 1 1 2 3。C 是把第 7 位算成 2 的常见失误。
练习 10 · 真题同型·高频 · 考点：'aaab' 的 nextval
模式串 'aaab' 的 nextval 数组是：
A. 0 1 2 3
B. 0 0 1 1
C. 0 0 0 0
D. 0 0 0 3
解析：选 D。next = 0 1 2 3；逐位判别：T[2]='a' 与 T[next[2]]=T[1]='a' 相同 → 继承 nextval[1]=0；T[3] 同理继承 → 0；j=4：T[4]='b' 与 T[next[4]]=T[3]='a' 不同 → 不继承，nextval[4]=next[4]=3。故 nextval = 0 0 0 3。全同字符的串（如 'aaa'）才是"全零"极端情形——C 正是没看末位 b 的最诱人陷阱。
练习 11 · 真题同型·高频 · 考点：BF 最好情况的比较次数
主串长 n、模式串长 m（n ≥ m），朴素模式匹配（BF）在最好情况下的比较次数是：
A. n − m + 1
B. m
C. n × m
D. m/2
解析：选 A。最好情形：每个起点第一次比较就失配（首位字符就对不上），共比较 n − m + 1 次。最坏是 (n−m+1)×m——两头的公式都要会写，2011 年前后多次以"最好/最坏/平均"三连问。
练习 12 · 真题同型·高频 · 考点：j 的滑动总量
KMP 算法中，模式串指针 j 在失配时会滑到 next[j]。整个匹配过程中 j 向前滑动（减小）的总量：
A. 可达 n×m 次
B. 不超过 m 次（上滑总量封顶）
C. 不超过 n 次
D. 与主串长度成正比
解析：选 B。j 每匹配成功一次 +1，全程最多 +m；每次失配下滑若干，但 j 永不为负 → 下滑总量 ≤ 上滑总量 ≤ m。这就是 O(n+m) 中 O(m) 的摊销来源，也是"KMP 为什么快"的标准答案。
练习 13 · 真题同型 · 考点：next 数组（交替串）
模式串 'ababa' 的 next 数组（位序从 1 起，next[1]=0）是：
A. 0 1 1 2 3
B. 0 1 2 3 4
C. 0 1 1 2 2
D. 0 1 1 2 4
解析：选 A。j=3 看 'ab' 无相等真前后缀 → 1；j=4 看 'aba'，'a'='a' 长 1 → 2；j=5 看 'abab'，'ab'='ab' 长 2 → 3。故 0 1 1 2 3。交替串是命题人最爱——注意它不像全同串那样逐位递增（那是 'aaaa' 才有）。
练习 14 · 真题同型 · 考点：nextval 的继承规则
模式串中 T[j] 与 T[next[j]] 相同，则 nextval[j] 应等于：
A. next[j]
B. j−1
C. nextval[next[j]]
D. 0
解析：选 C。跳到 next[j] 后要比较的字符与 T[j] 相同，这次比较必然再次失败，所以直接继承"跳板的跳板"的答案。注意是继承 nextval而不是 next——一路继承下去才是"跳过所有明知必败的比较"。
练习 15 · 真题同型 · 考点：BF 最坏情况的构造
设主串为 'aaaa…a'（n 个 a）、模式串为 'aaa…ab'（m−1 个 a 后跟一个 b）。朴素模式匹配在该情形下需要比较的次数约为：
A. n−m+1
B. (n−m+1)×m
C. n+m
D. n×log m
解析：选 B。每个起点都要一路比到模式串最后一个字符才失配，正是 (n−m+1)×m 的最坏量级。这个构造是"BF 为什么是 O(nm)"的实证，也是 KMP 存在的理由。
练习 16 · 真题同型 · 考点：最小周期（border 的应用）
某字符串 s 的长度为 10，其最长相等真前后缀长度为 4，则 s 的最小周期是：
A. 4
B. 5
C. 6
D. 10
解析：选 C。length − 最长 border = 10 − 4 = 6。直觉：若前 4 个字符与后 4 个字符相同，把串往前"推"6 格就能自我重合，所以 6 是周期；最小周期的定义就是"能自我重合的最小位移"。
