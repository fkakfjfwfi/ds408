🎯 学习目标（学完你应该能）

1.1 先说人话：什么是线性表

🚂 生活类比
线性表就是一列火车：车厢一节接一节，排成一条线。除了车头（第一个元素）和车尾（最后一个元素），每节车厢前面只有一节、后面也只挂一节——这就是"线性"关系的全部含义。

线性表是 n（n≥0）个数据元素的有限序列，记作 (a₁, a₂, …, aᵢ, aᵢ₊₁, …, aₙ)。注意两点：

逻辑结构，不是存储方式。"排队"是逻辑关系；至于排队的元素存在连续内存里（顺序表）还是用指针串起来（链表），是存储结构要回答的问题。408 选择题最爱在这里挖坑。
有限且可为空。元素个数 n 是有限的，n=0 时叫空表；每个元素类型相同、位序从 1 开始数。

1.2 顺序表：连排座位

🪑 生活类比
顺序表像电影院的一排连座：座位号连续，知道你的票号（下标）就能一步走到你的座位——这就是"随机访问 O(1)"。但中间来一个新朋友要插队，从他后面所有人全都得往后挪一位。

顺序表用一段地址连续的存储单元依次存放元素，逻辑相邻 ⟺ 物理相邻。设首地址为 LOC(A)，每个元素占 d 字节，则第 i 个元素的地址：

LOC(aᵢ) = LOC(A) + (i − 1) × d      // 位序 i 从 1 开始，下标 i−1 从 0 开始
📌 408 高频公式
位序 i ↔ 下标 i−1 的换算是选择题陷阱重灾区。另外记住：插入第 i 个位置（1≤i≤n+1），需要移动 n−i+1 个元素；删除第 i 个元素，需要移动 n−i 个。等概率下平均分别移动 n/2 和 (n−1)/2 个。

选一个位序（1~6），点"插入"看元素整体后移；点"删除"看元素整体前移。高亮的格子是正在移动的元素。

1.3 单链表：寻宝游戏

🗺️ 生活类比
单链表像寻宝游戏：你手里只有第一张线索卡（头指针），每张卡片上写着宝藏位置（数据域）和下一张卡片在哪儿（指针域）。想找第 5 张卡？必须从第 1 张一路顺藤摸瓜——这就是"不能随机访问"。

每个结点 = 数据域 + 指针域。插入和删除只需要改指针，不用搬元素，但查找必须从头遍历。带头结点的单链表是 408 默认画法——头结点不存数据，它存在的意义是让"在表头插入"和"在中间插入"逻辑统一。

typedef struct LNode {
    int data;               // 数据域
    struct LNode *next;     // 指针域：指向后继结点
} LNode, *LinkList;

// 在 p 所指结点之后插入新结点 s —— 两步顺序不能反！
s->next = p->next;          // ① 先让新结点"拉住"p 的后继
p->next = s;                // ② 再让 p 拉住新结点
⚠️ 为什么顺序不能反？
若先执行 p->next = s，p 原来的后继就丢了——没有任何指针指向它，这块内存成了"孤儿"，后面整条链全断。口诀：先钩新，后接旧。
🔬 实验室：单链表的插入与删除

1.4 双链表与循环链表（进阶速览）

双链表：每个结点加一根 prior 前驱指针，代价是多占空间，收益是 O(1) 找前驱、删除给定结点不用再从头找。循环单链表：尾结点的 next 指回头结点，从任意结点出发都能遍历全表；判空条件变成 head->next == head。循环双链表再加头结点的 prior 指向尾结点，形成双向环。

📌 408 考点：判空条件大乱斗
带头结点单链表：head→next == NULL；不带头结点单链表：head == NULL；循环单链表：head→next == head；循环双链表：head→next == head 且 head→prior == head。选择题几乎每年都换着花样考。

1.5 顺序 vs 链式：一张表决策

维度顺序表单链表
存储空间连续、要求整块，可静态分配或动态扩展散落各处，按需申请
存取方式随机访问 O(1)（按位序）顺序访问 O(n)
插入/删除O(n)，要整体挪元素找到位置后 O(1) 改指针
空间密度≥100%，无指针开销，可能闲置<100%，每结点多一个指针
适合场景按序号查改多、表长可预估、尾部增删频繁头/中部插删、表长变化大
✅ 决策口诀
"查多插少用顺序，插多查少用链表"。真题常给场景让你选存储结构，先问两个问题：按位序访问多不多？插删发生在哪里？

🚀 进阶深挖（教材级）

以下内容对齐严蔚敏《数据结构（C语言版）》与王道《数据结构考研复习指导》的处理深度，零基础可先跳过，二轮复习必看。

深挖 1 · 静态链表：用游标模拟指针

不使用指针，而是用数组下标（游标 cursor）充当"下一个结点在哪"的线索——这是严蔚敏教材的独门结构，也为"没有指针的语言怎么实现链表"给出答案。数组每个分量含 data 和 next（存后继的数组下标），下标 0 作头结点，备用空间串成一条备用链表，插入时从备用链摘一格、删除时归还一格。

#define MaxSize 100
typedef struct {
    int data;
    int next;      // 游标：后继在数组中的下标（-1 表结束）
} SLinkList[MaxSize];
// 优点：插入删除仍不需移动元素；缺点：容量预先固定、不能随机访问
// 408 考法：给游标状态表求插入/删除后的 next 值（2022 年曾以变体考过操作过程）

深挖 2 · 动态分配顺序表与均摊分析

静态分配 int data[MaxSize] 满了就死；动态分配 ElemType *data 配合 malloc/realloc 可以扩容。扩容要整体搬 n 个元素，看似很贵，但若每次容量翻倍，把扩容代价摊到之前的 n 次插入上，平均每次 O(1)——这就是"均摊分析"。注意：扩容后地址变了，指向旧元素的指针全部失效，这是 C 代码题的暗坑。

深挖 3 · 指针操作语句选序：真题最爱

2016 与 2021 两年连续考"删除结点的语句序列排序"，方法万能：① 画 before 图 ② 按依赖排序 ③ 画 after 图验证。两条铁律：先接新再断旧（防孤儿）；循环链表删除首元结点时要检查"被删的是不是尾指针所指"（尾指针要回退到头），单链表删除尾元时要找前驱（否则 next 域悬空）。

深挖 4 · 线性表大题三板斧（真题怎么考）

📌 历年大题规律（2009~2022 反复出现）
① 逆置是万金油（2010 年真题）：n 个整数循环左移 p 位，要求时间空间都尽可能高效 → 三次逆置法：逆置前 p 个、逆置后 n−p 个、整体逆置，时间 O(n)、空间 O(1)。
② 快慢指针找中点（2019 年真题）：把 (a₁…aₙ) 重排成 (a₁,aₙ,a₂,aₙ₋₁,…) → 快指针一次走两步找中点，后半段就地逆置，再两两交替合并。三步全是链表基本功的组合。
③ 辅助数组换时间（2015 年真题）：删除链表中 |data| 重复的结点（保留首次出现）→ 开长度 m+1 的标记数组，一趟扫过，时间 O(n)、空间 O(m)。
共同套路：能就地（O(1) 空间）绝不另开数组；要开数组先声明大小与数据域范围的关系。
// 三次逆置法核心代码（2010 大题解法骨架）
void Reverse(int a[], int l, int r) {
    for (; l < r; l++, r--) { int t = a[l]; a[l] = a[r]; a[r] = t; }
}
void LeftShift(int a[], int n, int p) {
    Reverse(a, 0, p - 1);      // 逆置前 p 个
    Reverse(a, p, n - 1);      // 逆置后 n-p 个
    Reverse(a, 0, n - 1);      // 整体逆置 → 循环左移完成
}

// 单链表就地逆置（头插法重建，高频手写题）
LinkList ReverseList(LinkList L) {
    LNode *p = L->next, *q;
    L->next = NULL;
    while (p) { q = p->next; p->next = L->next; L->next = p; p = q; }
    return L;
}
🌐 多源视角（不同书的讲法）
  • 【邓俊辉《数据结构（C++版）》】四种访问方式谱系：循秩访问（向量，地址 = 首地址 + 序号×sizeof，O(1)）、循位置访问（列表，靠 pred/succ 引用）、循值访问（散列）、循关键码访问（BST 靠比较缩小范围）。本站用法：先问"你要按什么方式访问"，再决定顺序表还是链表——比只背"插入删 O(n)"更贴设计动机。
  • 【Hello 算法】栈 = 被屏蔽掉部分操作的数组或链表：同一份单链表，插入删除都在头部就是栈，都在头部进尾部出就是队列。本站用法：给一个带头尾指针的单链表，改造成栈/队列只需改"在哪插在哪删"，结点结构一个字不用动。
  • 【均摊分析】翻倍扩容才叫均摊 O(1)：表满时申请 2 倍空间并整体搬移，装载因子始终 ≥ 1/2，n 次插入的搬移总量 ≤ 2n；若每次只加 1 格，n 次插入总搬移为 Θ(n²)——"均摊"这个词才立得住。
  • 【静态链表】备用链不回收就"删了也插不进"：0 号单元当备用链头，插入从备用链取格、删除把结点挂回备用链；删除时忘了回收，备用链很快耗尽，表现为"明明删了结点却插不进新结点"。
参考：邓俊辉《数据结构（C++版）》绪论；Hello 算法 hello-algo.com；严蔚敏《数据结构（C语言版）》2.3

⚠️ 本章避坑清单

位序从 1 数起，下标从 0 数起：a₃ 的下标是 2。算法题里先问自己"这是第几个还是数组第几格"。
单链表插入两步顺序不能反（先钩新，后接旧）；删除时先 q = p->next 存住再改链。
带头结点时，插入/删除第一个元素和其他位置逻辑统一——这正是头结点存在的意义，简答题爱考。
顺序表判满 L.length >= MaxSize，插入前必须检查；链表天然不满但判空条件别背串。
求表长：顺序表 O(1) 读 length；单链表要遍历 O(n)——这也是考点。

📝 章内练习（16 题 · 基础 → 提高 → 真题）

🟢 第一档 · 基础（4 题）

练习 1 · 考点：移动元素个数
长度为 n 的顺序表，在第 i 个位置（1 ≤ i ≤ n+1）插入一个新元素，需要向后移动的元素个数是：
A. n − i
B. n − i + 1
C. n − i + 1（从第 i 个到最后一个共 n−i+1 个）
D. i
解析：选 C（即 n−i+1 个）。插入在第 i 位，第 i 个到第 n 个元素（共 n−i+1 个）都要后移。记忆锚点：插得越靠前挪得越多，插到表尾（i=n+1）一个都不用挪。注意 B 和 C 本题数值相同是干扰排版，严谨写法就是 n−i+1。
练习 2 · 考点：判空条件
带头结点的单链表 L 为空的判定条件是：
A. L == NULL
B. L->next == NULL
C. L->next == L
D. L != NULL
解析：选 B。带头结点时头指针永远非空（指向头结点），空表的特征是"头结点后面没人"。A 是不带头结点的判空，C 是循环单链表的判空。三个选项放一起正好是本页考点框的复习。
练习 3 · 考点：指针操作顺序
在单链表中，p 指向某结点，s 指向待插入的新结点，要把 s 插到 p 之后，正确的操作序列是：
A. s->next = p->next; p->next = s;
B. p->next = s; s->next = p->next;
C. s->next = p; p->next = s;
D. p->next = s->next; s->next = p;
解析：选 A。口诀"先钩新，后接旧"。B 选项第二句执行时 p->next 已经是 s 自己了，s->next = s 成环且原后继丢失。这是算法大题手写代码的必对细节。
练习 4 · 考点：存储结构选型
某线性表最常用的操作是「按序号存取元素」和「在表尾插入删除」，最省时间的存储结构是：
A. 单链表
B. 带头结点的双循环链表
C. 循环单链表
D. 顺序表
解析：选 D。"按序号存取"直接锁定顺序表的随机访问 O(1)；表尾插删顺序表也都是 O(1)。口诀"查多插少用顺序"完整版是"按位序访问 + 尾部增删"场景。链表虽然尾部插删（带尾指针）也快，但按序号访问必须 O(n) 遍历，直接出局。

🟡 第二档 · 提高（4 题）

练习 5 · 考点：链表本质特性
下列关于单链表的说法，正确的是：
A. 可以随机访问任意元素，时间 O(1)
B. 结点的存储密度大于 1
C. 插入与删除无需移动元素，只需修改指针
D. 逻辑相邻的结点物理位置必须相邻
解析：选 C。链表的立身之本就是"改指针不搬数据"。A 是顺序表的能力；B 存储密度 = 数据域占比，恒小于 1（指针域占了空间）；D 逻辑相邻物理可以散落——这正是链表与顺序表的本质区别。
练习 6 · 考点：双链表插入语句序
在双链表中 p 所指结点之前插入 s 所指新结点，正确的语句序列是：
A. p->prior = s; s->next = p; s->prior = p->prior; p->prior->next = s;
B. s->prior = p->prior; p->prior->next = s; s->next = p; p->prior = s;
C. s->next = p; p->prior = s; s->prior = p->prior; p->prior->next = s;
D. p->prior = s; s->next = p; s->prior = p->prior; p->prior->next = s;
解析：选 B。A、C、D 都把 p->prior = s 放在了 s->prior = p->prior 之前——p 的原前驱线索被覆盖后，s->prior 取到的是 s 自己，形成自环，且原前驱的 next 也没接上。B 先安顿新结点的两根指针（prior 记住旧前驱、next 指向 p），再改邻居，信息零丢失。口诀：双链表插入"先安顿新，再改邻居"，做题时逐句检查"这句用到的信息是否已被覆盖"。
练习 7 · 考点：顺序表就地删除
在顺序表中删除所有值等于 x 的元素，要求时间空间均尽可能高效，最优算法的时间/空间复杂度是：
A. O(n) / O(1)
B. O(n) / O(n)
C. O(n²) / O(1)
D. O(nlogn) / O(1)
解析：选 A。双指针一遍扫描：k 记录"不等于 x 的元素应放的位置"，遍历一遍把保留元素前移覆盖，最后 length = k。C 是"每删一个整体前移一次"的朴素写法——408 大题评分点就在能否想到 O(n) 一遍法。
练习 8 · 考点：尾指针循环单链表
设循环单链表带尾指针 rear（rear 指向尾元结点，首元结点为 rear->next），则「在表尾插入新结点」「删除表尾结点（不含头结点）」的时间复杂度分别是：
A. O(1) / O(1)
B. O(n) / O(1)
C. O(1) / O(1)（尾指针万能）
D. O(1) / O(n)
解析：选 D。尾插：在 rear 后插入再令 rear 后移，O(1)。但删尾元需要它的前驱——循环单链表只能从 rear->next（头结点）绕一整圈找，O(n)。教训：尾指针只服务"尾部"，删除尾部恰恰要"尾部的前驱"，这正是双链表/双循环链表存在的理由。

🔴 第三档 · 真题（8 题 · 原题核对版）

练习 9 · 考点：双循环链表删除语句序
已知一个带有表头结点的双向循环链表 L，结点结构为 (prior, data, next)，p 指向链表中某一结点（p ≠ 头结点）。删除 p 所指结点的正确语句序列是：
A. free(p); p->prior->next = p->next; p->next->prior = p->prior;
B. p->next->prior = p->next; p->prior->next = p->prior; free(p);
C. p->prior->next = p->next; free(p); p->next->prior = p->prior;
D. p->next->prior = p->prior; p->prior->next = p->next; free(p);
解析：选 D。A 先释放再用 p->prior/p->next，属于"释放后访问"；B 两句抄错方向，把邻居的指针全指向 p 自己，链彻底断掉；C 中 free 后再访问 p->prior 同样违规。方法：画三个结点的 before 图，逐句画 after 图，凡 free 提前或指针被覆盖的选项直接排除。
练习 10 · 考点：循环链表删首元 + 边界
设带有头结点的非空单循环链表 L，头指针为 h，尾指针 p 指向表中最后一个结点，q 指向第一个数据结点。删除 L 的第一个数据结点的正确语句序列是：
A. h->next = q->next; free(q);（不总是对）
B. free(q); h->next = q->next;
C. q->next = h; free(q); p = h;
D. h->next = q->next; if (q == p) p = h; free(q);
解析：选 D。这题的杀招是边界：若链表只有一个数据结点，q == p，删除后尾指针 p 必须回退到头结点 h，否则 p 悬空。A 忽略了这个特例——表长为 1 时循环链断成"野环"；B 先释放后访问；C 先把 q->next 指向 h 再释放，但 h->next 还指着已释放的 q。真题连续两年考"语句选序 + 边界修正"，考前务必亲手画一遍表长为 1 的情形。
练习 11 · 考点：链表合并的复杂度
已知两个长度分别为 m 和 n 的升序链表（m、n 均大于 0），若将它们合并为长度为 m+n 的降序链表，最坏情况下的时间复杂度是：
A. O(min{m, n})
B. O(m + n)
C. O(m · n)
D. O(max{m, n})
解析：选 D。降序输出 → 用头插法建结果链表：每次比较两条链的队首，小者摘下头插进结果；一条链耗尽后，另一条剩余结点直接逐个头插（无需再比较）。最坏比较次数 = max{m, n}。B 的 O(m+n) 是移动结点总数——比较次数与移动次数分开数，这是本题的命题点。
练习 12 · 考点：链表重排大题思路（2019 年大题 · 选择化）
2019 年真题大题：将线性表 (a₁, a₂, …, aₙ) 改为 (a₁, aₙ, a₂, aₙ₋₁, …)，采用带头结点单链表存储，要求时间空间尽可能高效。最优解法的三个步骤依次是：
A. 整体逆置 → 快慢指针找中点 → 交替合并
B. 快慢指针找中点 → 后半段就地逆置 → 两段交替合并
C. 复制到辅助数组 → 奇偶交替取数 → 回写链表
D. 对链表排序 → 从两端取数 → 重新建表
解析：选 B。快指针一次走两步、慢指针一步，快指针到尾时慢指针恰在中点；把后半段就地逆置（头插法 O(1) 空间）；再从前半段与逆置后的后半段轮流摘结点合并。C 能做对但空间 O(n) 不满足"尽可能高效"——真题评分标准里空间不达标直接扣分。三步分别对应本页深挖 4 的基本功。
练习 13 · 考点：循环左移（2010 年数据结构大题 · 选择化）
将含 n 个整数的顺序表循环左移 p 位（1 ≤ p ≤ n），要求时间和辅助空间都尽可能高效，最优解法的时空复杂度是：
A. O(n) / O(p)
B. O(n) / O(1)
C. O(p×n) / O(1)
D. O(nlog₂n) / O(1)
解析：选 B。三次逆置——前 p 个逆置、后 n−p 个逆置、整体逆置，每元素最多搬 2 次，空间只用常数个临时变量。C 是逐位搬移的朴素解，O(pn)。这是 2010 年大题的解法骨架，代码见本章深挖 4。
练习 14 · 考点：两链表公共后缀（真题同型）
两个带头结点的单链表 A、B 长度分别为 m、n，从某个结点起两表的后继结点完全相同（形成 Y 形）。在时间和空间都尽可能高效的条件下，找出首个公共结点的最优做法是：
A. 双重循环逐对比较，O(mn)
B. 先求两表长度 m、n，让较长者先走 |m−n| 步，再两表同步前进，首个指针相同的结点即答案，O(m+n) / O(1)
C. 把 A 的所有结点地址存入散列表，再遍历 B，O(m+n) / O(m)
D. 把两表整体逆置后从头比较
解析：选 B。Y 形共用尾部意味着"末尾对齐后，公共段起点必然同步到达"——先让长表走完富余的 |m−n| 步，两指针就齐平了。C 也对但空间 O(m)，不满足"空间尽可能高效"。D 破坏链表结构不可取。
练习 15 · 考点：主元素（2013 年数据结构大题 · 选择化）
长度为 n 的整数序列中，若某元素的出现次数超过 n/2，称其为主元素。在时间、空间都尽可能高效的前提下，判断主元素的最优做法是：
A. 排序后取中间元素再计数，O(nlog₂n)
B. 散列表计数，O(n) / O(n)
C. 摩尔投票法：一次遍历"抵消"，再二次遍历验证，O(n) / O(1)
D. 双重循环统计每个元素出现次数，O(n²)
解析：选 C。摩尔投票的思路是"成对抵消"——不同则抵消、相同则计数，最后剩下的候选者再数一遍确认（必须验证，只投票不验证会漏判）。2013 年大题的满分点就在"O(n) 时间 + O(1) 空间 + 二次验证"。
练习 16 · 考点：静态链表插入
静态链表用数组模拟，每个分量含 data 与 next（存后继的数组下标），0 号单元为头结点，备用结点串成备用链。设结点 a、e、f 的数组下标分别为 2、5、7，且 a 是 e 的前驱。现要把 f 插入 a 与 e 之间，正确的操作是：
A. 只改 a 的 next 为 7，f 的 next 保持原值
B. 先改 a 的 next 为 7，再把 f 的 next 改为 5
C. 先把 f 从备用链摘下（改备用链头的 next），再令 f.next = 5、a.next = 7
D. 直接把 e 的 next 改为 7
解析：选 C。静态链表插入和动态链表一个道理——先钩新，后接旧，还要额外管一件事：从备用链摘结点（否则这个格子会被重复分配）。B 少了摘链这步；A、D 会让 e 之后断链。
