第 1 章 · 线性表

数据结构的第一块地基。408 卷面上直接考线性表的题不少，更重要的是：后面栈、队列、树、图全都建立在它的思想之上。

预计学习 2~3 小时 · 动画课堂 1 集 · 练习 4 题 · 打卡 6 项

🎯 学习目标（学完你应该能）
① 说出线性表的逻辑特性：除表头表尾外，每个元素有且仅有一个直接前驱和直接后继；
② 手画顺序表插入/删除时元素的移动过程，说出对应时间复杂度；
③ 默写单链表"后插"的两步指针操作，并解释为什么顺序不能反；
④ 给定使用场景，判断选顺序存储还是链式存储更合适。

1.1 先说人话：什么是线性表

🚂 生活类比
线性表就是一列火车：车厢一节接一节，排成一条线。除了车头（第一个元素）和车尾（最后一个元素），每节车厢前面只有一节、后面也只挂一节——这就是"线性"关系的全部含义。

线性表是 n（n≥0）个数据元素的有限序列，记作 (a₁, a₂, …, aᵢ, aᵢ₊₁, …, aₙ)。注意两点：

逻辑结构，不是存储方式。"排队"是逻辑关系；至于排队的元素存在连续内存里（顺序表）还是用指针串起来（链表），是存储结构要回答的问题。408 选择题最爱在这里挖坑。
有限且可为空。元素个数 n 是有限的，n=0 时叫空表；每个元素类型相同、位序从 1 开始数。

1.2 顺序表：连排座位

🪑 生活类比
顺序表像电影院的一排连座：座位号连续，知道你的票号（下标）就能一步走到你的座位——这就是"随机访问 O(1)"。但中间来一个新朋友要插队，从他后面所有人全都得往后挪一位。

顺序表用一段地址连续的存储单元依次存放元素，逻辑相邻 ⟺ 物理相邻。设首地址为 LOC(A)，每个元素占 d 字节，则第 i 个元素的地址：

LOC(aᵢ) = LOC(A) + (i − 1) × d      // 位序 i 从 1 开始，下标 i−1 从 0 开始
📌 408 高频公式
位序 i ↔ 下标 i−1 的换算是选择题陷阱重灾区。另外记住：插入第 i 个位置（1≤i≤n+1），需要移动 n−i+1 个元素；删除第 i 个元素，需要移动 n−i 个。等概率下平均分别移动 n/2 和 (n−1)/2 个。
🔬 实验室：顺序表的插入与删除
选一个位序（1~6），点"插入"看元素整体后移；点"删除"看元素整体前移。高亮的格子是正在移动的元素。

1.3 单链表：寻宝游戏

🗺️ 生活类比
单链表像寻宝游戏：你手里只有第一张线索卡（头指针），每张卡片上写着宝藏位置（数据域）和下一张卡片在哪儿（指针域）。想找第 5 张卡？必须从第 1 张一路顺藤摸瓜——这就是"不能随机访问"。

每个结点 = 数据域 + 指针域。插入和删除只需要改指针，不用搬元素，但查找必须从头遍历。带头结点的单链表是 408 默认画法——头结点不存数据，它存在的意义是让"在表头插入"和"在中间插入"逻辑统一。

typedef struct LNode {
    int data;               // 数据域
    struct LNode *next;     // 指针域：指向后继结点
} LNode, *LinkList;

// 在 p 所指结点之后插入新结点 s —— 两步顺序不能反！
s->next = p->next;          // ① 先让新结点"拉住"p 的后继
p->next = s;                // ② 再让 p 拉住新结点
⚠️ 为什么顺序不能反？
若先执行 p->next = s，p 原来的后继就丢了——没有任何指针指向它，这块内存成了"孤儿"，后面整条链全断。口诀：先钩新，后接旧。
🔬 实验室：单链表的插入与删除
点"在第 3 个结点后插入"，逐步看两根指针的动作；点"删除第 3 个结点"看被跳过的结点如何出局。虚线箭头是"即将建立/断开"的指针。

1.4 双链表与循环链表（进阶速览）

双链表：每个结点加一根 prior 前驱指针，代价是多占空间，收益是 O(1) 找前驱、删除给定结点不用再从头找。循环单链表：尾结点的 next 指回头结点，从任意结点出发都能遍历全表；判空条件变成 head->next == head。循环双链表再加头结点的 prior 指向尾结点，形成双向环。

📌 408 考点：判空条件大乱斗
带头结点单链表：head→next == NULL；不带头结点单链表：head == NULL；循环单链表：head→next == head；循环双链表：head→next == head 且 head→prior == head。选择题几乎每年都换着花样考。

1.5 顺序 vs 链式：一张表决策

维度顺序表单链表
存储空间连续、要求整块，可静态分配或动态扩展散落各处，按需申请
存取方式随机访问 O(1)（按位序）顺序访问 O(n)
插入/删除O(n)，要整体挪元素找到位置后 O(1) 改指针
空间密度≥100%，无指针开销，可能闲置<100%，每结点多一个指针
适合场景按序号查改多、表长可预估、尾部增删频繁头/中部插删、表长变化大
✅ 决策口诀
"查多插少用顺序，插多查少用链表"。真题常给场景让你选存储结构，先问两个问题：按位序访问多不多？插删发生在哪里？

⚠️ 本章避坑清单

位序从 1 数起，下标从 0 数起：a₃ 的下标是 2。算法题里先问自己"这是第几个还是数组第几格"。
单链表插入两步顺序不能反（先钩新，后接旧）；删除时先 q = p->next 存住再改链。
带头结点时，插入/删除第一个元素和其他位置逻辑统一——这正是头结点存在的意义，简答题爱考。
顺序表判满 L.length >= MaxSize，插入前必须检查；链表天然不满但判空条件别背串。
求表长：顺序表 O(1) 读 length；单链表要遍历 O(n)——这也是考点。

📝 章内练习

练习 1 · 考点：移动元素个数
长度为 n 的顺序表，在第 i 个位置（1 ≤ i ≤ n+1）插入一个新元素，需要向后移动的元素个数是：
A. n − i
B. n − i + 1
C. n − i + 1（从第 i 个到最后一个共 n−i+1 个）
D. i
解析：选 C（即 n−i+1 个）。插入在第 i 位，第 i 个到第 n 个元素（共 n−i+1 个）都要后移。记忆锚点：插得越靠前挪得越多，插到表尾（i=n+1）一个都不用挪。注意 B 和 C 本题数值相同是干扰排版，严谨写法就是 n−i+1。
练习 2 · 考点：判空条件
带头结点的单链表 L 为空的判定条件是：
A. L == NULL
B. L->next == NULL
C. L->next == L
D. L != NULL
解析：选 B。带头结点时头指针永远非空（指向头结点），空表的特征是"头结点后面没人"。A 是不带头结点的判空，C 是循环单链表的判空。三个选项放一起正好是本页考点框的复习。
练习 3 · 考点：指针操作顺序
在单链表中，p 指向某结点，s 指向待插入的新结点，要把 s 插到 p 之后，正确的操作序列是：
A. s->next = p->next; p->next = s;
B. p->next = s; s->next = p->next;
C. s->next = p; p->next = s;
D. p->next = s->next; s->next = p;
解析：选 A。口诀"先钩新，后接旧"。B 选项第二句执行时 p->next 已经是 s 自己了，s->next = s 成环且原后继丢失。这是算法大题手写代码的必对细节。
练习 4 · 考点：存储结构选型
某线性表最常用的操作是「按序号存取元素」和「在表尾插入删除」，最省时间的存储结构是：
A. 单链表
B. 带头结点的双循环链表
C. 循环单链表
D. 顺序表
解析：选 D。"按序号存取"直接锁定顺序表的随机访问 O(1)；表尾插删顺序表也都是 O(1)。口诀"查多插少用顺序"完整版是"按位序访问 + 尾部增删"场景。链表虽然尾部插删（带尾指针）也快，但按序号访问必须 O(n) 遍历，直接出局。
