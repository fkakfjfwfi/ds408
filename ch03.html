第 3 章 · 树与二叉树

3.1 先说人话：什么是树

🌳 生活类比
树就是家谱（倒过来看）：一位祖先（根）开枝散叶，每位成员只属于一个直系分支，兄弟姐妹互不通婚（任意两个结点有且仅有唯一路径）。公司组织架构、电脑里的文件夹，全是树。

树是 n（n≥0）个结点的有限集合，n=0 时为空树；否则有且仅有一个根，其余结点分成 m 个互不相交的子集，每个子集又是一棵树（递归定义——树生树）。

术语一句话解释408 提醒
结点的度该结点有几个孩子树的度 = 各结点度的最大值
叶子结点度为 0 的结点n₀ = n₂ + 1 是选择题钉子户
深度/高度从根算起共几层空树深度 0，只有根深度 1（看题目约定！）
有序树孩子之间有左右次序二叉树是有序树：左右子树交换就是不同的树
✅ 万能恒等式
树的总结点数 = 总度数 + 1（每个结点被一条边指着，除根之外）。配合「度 i 的结点数记 nᵢ」可以推出 n₀ = n₂ + 1（二叉树）——考场上现推，别死记。

3.2 二叉树与五大性质

二叉树：每个结点至多两棵子树（度 ≤ 2），且子树分左右，次序不能颠倒。注意：二叉树 ≠「度为 2 的树」——它可以只有左孩子或只有右孩子，甚至为空。

性质 1：第 i 层至多 2^(i−1) 个结点（i≥1）。每层翻倍，祖传一变二。
性质 2：深度为 k 的二叉树至多 2^k − 1 个结点（等比数列求和）。
性质 3：n₀ = n₂ + 1。推导：n = n₀+n₁+n₂，总度数 = n₁+2n₂ = n−1，两式相减即得。
性质 4（完全二叉树）：n 个结点的完全二叉树高度 ⌈log₂(n+1)⌉ 或 ⌊log₂n⌋+1。
性质 5（完全二叉树编号）：按层编号后，结点 i 的左孩子是 2i、右孩子 2i+1、双亲 ⌊i/2⌋（编号从 1 起）。2i > n ⇒ i 是叶子。
📌 满二叉树 vs 完全二叉树
满二叉树：每层都塞满（深度 k 恰有 2^k−1 个）。完全二叉树：只允许最后一层缺右边连续的若干结点。判断口诀："从左到右数过来不能跳坑"。堆、线段树都长这样，所以它们能用数组存。

3.3 二叉树的存储

顺序存储：按完全二叉树编号存进数组，i 的孩子是 2i/2i+1。对完全二叉树零浪费；但一般二叉树要补成完全二叉树存，最坏深度为 k 的单支树需要 2^k−1 个格子，天价浪费。

链式存储（二叉链表）：每个结点存 data | lchild | rchild。n 个结点共 2n 个指针域，其中 n+1 个为空（n+1 条边 + 1 个根没人指）——这些空指针正是下一节线索化要回收的资源。

typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

3.4 遍历：本章的心脏 ❤️

遍历 = 按某种规则每个结点访问一次。三种深度优先遍历只差"根"的时机：

遍历口诀记忆
先序 PreOrder根 → 左 → 右根第一个被访问
中序 InOrder左 → 根 → 右根在中间；对 BST 中序=升序
后序 PostOrder左 → 右 → 根根最后走；适合"自底向上"统计
层序 LevelOrder一层一层从左到右用队列实现（第 2 章的知识回收！）
📌 408 铁律：重建二叉树必须有中序
先序+后序 不能唯一确定一棵二叉树（只有一个孩子时分不清是左是右）。能唯一重建的组合：先序+中序、后序+中序、层序+中序。方法：先序/后序第一个/最后一个必是根，拿根去中序里切出左右子树，递归。
🔬 遍历实验室：点一个按钮，看树被"走"一遍
四个按钮对应四种遍历，动画会按顺序逐个点亮结点并显示序列。先自己心里默写一遍，再点按钮对答案。
示例树：A( B(D,E), C( ,F) )——D、E 是 A 的孙辈，F 只有左亲没有叔伯……自己先画画看。

3.5 线索二叉树（进阶）

上面说了 n 个结点有 n+1 个空指针。把它们利用起来：若 lchild 为空，让它指向前驱；rchild 为空指向后继（指中序序列里的前驱后继，就叫中序线索二叉树）——遍历不用栈不用递归，直接顺线索走。为区分"孩子指针"和"线索指针"，每结点加两个布尔标志位 tag。

⚠️ 线索二叉树高频陷阱
中序线索二叉树里，某结点 rchild 指向的不是它的"孩子"而是"中序后继"——画图判断"指向谁"时，先把该树的中序序列写出来再说。选择题最爱考"X 的 rchild 指向谁"。

3.6 树、森林与哈夫曼树（进阶）

树 ↔ 二叉树转换：左孩子右兄弟表示法——树的每个结点，第一个孩子挂到左指针，右兄弟挂到右指针。转换后二叉树的根没有右子树。森林 = 多棵树的根用兄弟链串起来。

哈夫曼树：n 个带权叶子，构造 WPL（带权路径长度）最小的二叉树。方法：每次从集合里挑权值最小的两个合并成新结点，重复直到只剩一棵树。哈夫曼树没有度为 1 的结点，n 个叶子则共 2n−1 个结点。

📌 哈夫曼编码：压缩的灵魂
左分支记 0、右分支记 1，从根到叶子的路径就是该字符的编码。因为字符只出现在叶子（不会走到半路撞上别人），所以编码互不为前缀，解码不会歧义。真题：给权值集合构造哈夫曼树 → 求 WPL / 某字符码长 / 总编码长度。

⚠️ 本章避坑清单

深度/高度的定义看题目约定：有的教材根算第 0 层。408 题面会写清楚"根为第 1 层"，照题面算，别背死结论。
n₀ = n₂ + 1 只对二叉树成立；一般树没有这个结论（一般树是 n = 总度数 + 1）。
完全二叉树判断画格子最稳：从 1 号开始编号画数组，中间出现空洞就不是完全二叉树。
先序+后序重建是经典错误选项——只有先序+中序（或后序+中序、层序+中序）才唯一。
哈夫曼构造每次合并的"新结点"也参与后续比较，别只盯着初始权值挑。
遍历的递归算法要能默写（大题常以遍历为骨架改造），非递归实现靠栈——又是第 2 章。

📝 章内练习

练习 1 · 考点：n₀ = n₂ + 1
一棵二叉树有 20 个叶子结点、8 个度为 1 的结点，则度为 2 的结点个数是：
A. 17
B. 19
C. 21
D. 28
解析：选 B。n₀ = n₂ + 1 ⇒ n₂ = n₀ − 1 = 20 − 1 = 19。度为 1 的结点数完全不影响这个恒等式——8 是干扰项。总结点数 = 20 + 8 + 19 = 47（顺带自检）。
练习 2 · 考点：完全二叉树性质
一棵完全二叉树有 100 个结点，则叶子结点的个数是：
A. 49
B. 50
C. 50（编号 ⌈100/2⌉+1 ~ 100）
D. 64
解析：选 C。完全二叉树按 1 编号，结点 i 有孩子当且仅当 2i ≤ n。最后有孩子的结点编号是 ⌊n/2⌋ = 50，故叶子是 51~100 号，共 50 个。口诀：完全二叉树叶子数 = ⌈n/2⌉。
练习 3 · 考点：遍历与重建
某二叉树的先序序列为 ABDCE，中序序列为 BDAEC，则它的后序序列是：
A. DBECA
B. BDECA
C. DBCEA
D. 无法确定
解析：选 A。先序第一个 A 是根；中序中 A 把树切成左(BD)、右(EC)。左子树：先序 BD、中序 BD ⇒ B 是根、D 是右孩子（中序 B 在 D 前）。右子树：先序 CE、中序 EC ⇒ C 是根、E 是左孩子。后序 = 左(D B) 右(E C) 根(A) = DBECA。动笔切块，30 秒搞定。
练习 4 · 考点：哈夫曼树
以权值 {2, 3, 4, 7} 构造哈夫曼树，其带权路径长度 WPL 是：
A. 21
B. 30
C. 32
D. 26
解析：选 B。构造：最小两个合并 2+3=5 → 集合{4,5,7}；再合并 4+5=9 → {7,9}；最后 7+9=16 为根。权 2、3 在第 3 层，4 在第 2 层，7 在第 1 层，WPL = 2×3 + 3×3 + 4×2 + 7×1 = 30。速算技巧：WPL = 每次合并产生的新结点值之和 = 5 + 9 + 16 = 30，考场上这样算最快。
